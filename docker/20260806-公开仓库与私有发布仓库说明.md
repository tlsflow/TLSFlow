# 公开仓库与私有发布仓库说明

## 公开仓库职责

公开仓库只提供本地可复现构建，不保存 Docker Hub 凭据，也不自动推送镜像。

本地构建小型版：

```text
node docker/build-local.mjs --architecture small
```

本地构建标准版：

```text
node docker/build-local.mjs --architecture standard
```

默认使用当前主机对应的 `linux/amd64` 或 `linux/arm64` 平台，并通过 `--load` 将镜像加载到本地 Docker。也可以显式指定：

```text
node docker/build-local.mjs --architecture all --platform linux/amd64
```

该脚本不会执行 `docker login`，也不会执行 `--push`。

## 私有发布仓库职责

私有发布仓库保存以下内容：

- 公开仓库地址；
- 要发布的公开仓库 Tag 或 Commit；
- Docker Hub 命名空间；
- 发布渠道和镜像 Tag 规则；
- Docker Hub 用户名与 Access Token Secret；
- 发布流水线和审批规则。

私有发布仓库应固定公开仓库版本后，再调用公开仓库中的发布脚本：

```text
git clone --branch "$GCAC_SOURCE_REF" "$GCAC_PUBLIC_REPOSITORY" public-source
printf '%s' "$DOCKERHUB_TOKEN" | docker login --username "$DOCKERHUB_USERNAME" --password-stdin
export GCAC_DOCKER_LOGIN_CONFIRMED=true
node public-source/docker/publish-images.mjs --namespace "$DOCKERHUB_NAMESPACE" --latest
```

真实流水线中，`DOCKERHUB_TOKEN` 必须通过 CI Secret 注入，禁止写入 `release.env`、仓库文件、命令行参数或日志。

## 私有发布仓库建议文件

```text
release/
  release.env.example
  publish.sh
  ci/
    publish.yml
```

`release.env.example` 只能保存非敏感配置：

```text
GCAC_PUBLIC_REPOSITORY=<公开仓库地址>
GCAC_SOURCE_REF=v1.0.0
DOCKERHUB_NAMESPACE=<Docker Hub 命名空间>
```

产品版本唯一来自公开仓库根目录的 `version` 文件。发布脚本默认读取该文件作为镜像标签；`GCAC_SOURCE_REF` 只用于固定源码 Tag，不再单独维护 `GCAC_RELEASE_VERSION`。

`DOCKERHUB_USERNAME` 和 `DOCKERHUB_TOKEN` 必须只存在于 CI Secret 管理系统。

发布契约见 [publish-contract.json](C:/Code/GCAC/docker/publish-contract.json)。该文件属于公开仓库接口，不包含任何私有仓库地址或凭据。
