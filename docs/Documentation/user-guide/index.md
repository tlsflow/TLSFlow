# 用户指南

用户指南按“准备对象 → 选择能力 → 执行部署 → 验证结果 → 处理风险”的顺序组织。

## 主要主题

- 身份、权限、Secret、审批和审计。
- 证书资产、CA、格式和制品。
- Agent 设备、非 Agent 目标、Gateway 和执行通道。
- 应用资产、ManagedTarget 和证书绑定。
- 工作流模板、输入配置和执行绑定。
- 部署计划、预检、执行、验证、回滚和结果。
- 监控、通知、自动化、凭据和报表。
