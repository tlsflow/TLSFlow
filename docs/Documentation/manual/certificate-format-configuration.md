# 证书格式配置

格式配置是“部署时生成什么文件”的预设，不是证书本身，也不会单独触发部署。页面支持 PEM、PFX、JKS、P7B 等常用格式，并允许为不同系统保存多套配置。

> 【截图占位：证书格式配置列表，显示配置名称、系统平台、输出格式和状态】

## 新建格式配置

1. 进入“证书管理 → 证书格式配置”，点击“新建”。
2. 选择系统平台和运行环境（如 Linux、Windows 或 Java）。点击“套用模板”可带出常用设置。
3. 填写配置名称，选择输出格式：PEM、PFX、JKS、P7B、CER、CRT 或自定义格式。
4. 按需要设置文件扩展名、证书链顺序、证书内容编码和别名（alias）。
5. PFX/JKS 需要密码时，选择已有的安全凭据，或在密码输入框中录入后让系统保存为凭据。
6. 点击“保存”，返回列表确认配置可用。

## 在应用资产中使用

1. 打开“资产中心 → 应用资产”，新建或编辑应用资产。
2. 在证书格式或部署输入区域选择配置。
3. 检查预览中的文件名、扩展名、证书链和所需凭据。
4. 保存应用资产，在部署预检中确认能够生成目标文件。

格式配置只有在应用资产或工作流实际选中后才会生效；单独保存配置不会生成文件。

## 各格式需要什么

| 格式 | 适用场景 | 需要注意 |
| --- | --- | --- |
| PEM | Nginx、Apache、常见 Linux 服务 | 通常需要叶子证书、私钥和按顺序排列的证书链 |
| PFX/P12 | Windows、部分网关和中间件 | 需要私钥、密码和证书别名 |
| JKS | Java 应用服务器 | 需要私钥、密码和证书别名 |
| P7B/P7C/SPC | 只需要证书链的场景 | 不包含私钥，不能单独完成 HTTPS 部署 |

编辑配置会影响后续新建的部署计划；已经开始或已经完成的执行仍按当时保存的配置进行。删除前请先确认没有应用资产在使用，系统会阻止误删正在使用的配置。

输出格式的边界如下：PEM 由证书、私钥和有序链组成；PFX/P12 和 JKS 还需要密码与别名；P7B/P7C/SPC 只携带证书链，不能替代私钥。密码只能来自已保存的安全凭据，系统会在生成前校验，错误密码不会生成可部署制品。
