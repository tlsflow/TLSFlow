# 角色

角色把一组业务权限交给一类人员。进入“系统设置 → 角色”后，可以创建角色、限定可管理的对象范围，再把用户或组加入角色。

## 创建角色并授权

1. 点击“创建角色”，填写角色名称和职责说明，例如“证书操作员”“审计查看员”。
2. 在“可授权对象”树中展开需要管理的类别，选择证书、应用、日志或系统设置；展开类别后可选择全部记录，也可只选择某一条记录。
3. 选择“业务权限级别”：一般操作人员使用“使用者”，需要负责审核和管理的人员使用“管理者”。
4. 选择权限效果。正常授权选择“允许”；只有在明确需要排除某个范围时才使用“拒绝”。
5. 点击“创建角色”。保存后点击该角色的“详情”，确认对象范围和权限显示正确。

## 给已有角色增加权限

1. 在角色列表找到目标角色，点击“授权”。
2. 刷新对象列表，展开对象树并勾选新增范围。
3. 选择权限级别和效果，点击“授予权限”。
4. 回到角色“详情”核对“当前角色权限”列表，确认范围没有超出职责。

## 分配成员

1. 点击角色行的“分配成员”。
2. 在“成员类型”选择“用户”或“组”。禁用用户不会出现在可分配列表中。
3. 勾选一个或多个成员，确认“已选成员”摘要无误后点击“分配成员”。
4. 在角色详情的“已分配成员”列表复核结果。

删除角色前先把成员迁移到其他角色，并确认该角色没有仍在使用的权限范围。内置角色不可删除；角色权限变更会影响后续操作，已完成的历史记录不会被改写。
