# 证书管理

“证书管理”用于准备和维护证书材料。页面按“证书资产 → 自动化/CA 操作 → 格式配置”的顺序使用，完成准备后再到“资产中心”绑定应用。

| 页面 | 用途 |
| --- | --- |
| 证书资产 | 导入、查看、删除证书版本，查看使用关系 |
| ACME 自动化 | 配置 ACME 提供商、账户和申请/续签任务 |
| CA 操作 | 查看 CA 层级、同步对象和内部 CA |
| 证书格式配置 | 定义 PEM、PFX/P12、JKS 等部署输出格式 |

## 推荐操作顺序

1. **准备证书资产**：导入证书、私钥和证书链，确认域名及有效期。
2. **需要自动申请或续期时**：配置 ACME 提供商和任务；手工导入的证书可跳过此步。
3. **使用内部或企业 CA 时**：在“CA 操作”中查看 CA 层级和同步状态，确认签发来源可用。
4. **准备部署文件时**：在“证书格式配置”中选择目标系统需要的输出格式，例如 PEM、PFX/P12 或 JKS。
5. **绑定业务应用**：进入“资产中心 → 应用资产”，选择证书、设备和部署方式。
6. **执行部署**：进入“证书部署”，完成预检和审批（如启用）后再提交。

## 各页面怎么用

| 页面 | 适合做什么 | 完成标志 |
| --- | --- | --- |
| 证书资产 | 导入证书、查看版本、确认使用范围 | 列表中显示有效状态和预期到期时间 |
| ACME 自动化 | 自动申请、续期和跟踪 ACME 证书 | 任务已启用，最近一次运行有结果 |
| CA 操作 | 查看 CA 层级、同步状态和内部 CA | CA 状态正常、同步时间为最新 |
| 证书格式配置 | 预先定义部署所需文件格式 | 格式配置可在应用资产中选择 |

## 使用时的关键点

- 同一域名可以有多个证书版本。部署前请确认选的是需要使用的那一版，而不是只看名称。
- 格式配置只负责“生成什么样的部署文件”，不会自动把证书写入服务器。
- 删除或停用前，先查看是否仍有应用、自动化任务或部署计划在使用。
- 页面中的时间按浏览器本地时间显示；证书是否过期以到期时间和当前状态共同判断。
