# 证书管理

“证书管理”是准备证书、维护证书来源并设置部署文件格式的入口。可以先把证书准备好，再到“资产中心”选择应用和设备。

| 页面 | 用途 |
| --- | --- |
| 证书资产 | 导入、查看、删除证书版本，查看使用关系 |
| ACME 自动化 | 配置 ACME 提供商、账户和申请/续签任务 |
| CA 操作 | 查看 CA 层级、同步对象和内部 CA |
| 证书格式配置 | 定义 PEM、PFX/P12、JKS 等部署输出格式 |

## 一次完整的使用流程

1. 在“证书资产”导入已有证书，或从 ACME 自动申请证书。
2. 如果证书由企业 CA 管理，在“CA 操作”确认 CA 和同步状态正常。
3. 在“证书格式配置”预先准备目标系统需要的 PEM、PFX/P12、JKS 等格式。
4. 打开“资产中心 → 应用资产”，选择业务、证书版本和可执行目标。
5. 进入部署流程，先查看预检结果；需要审批时完成审批后再执行。

## 页面入口和完成标志

| 页面 | 适合做什么 | 完成标志 |
| --- | --- | --- |
| 证书资产 | 导入证书、查看版本和使用关系 | 列表能看到域名、状态和到期时间 |
| ACME 自动化 | 自动申请、续签并跟踪任务 | 提供商可用，任务有最近一次结果 |
| CA 操作 | 查看 CA 层级、对象和同步记录 | CA 状态正常、同步记录显示成功 |
| 证书格式配置 | 设置部署文件的输出方式 | 配置能在应用资产中被选中 |

## 使用时的关键点

- 同一域名可能有多个版本，部署前同时核对域名、到期时间和版本指纹。
- 格式配置只决定生成哪类文件，不会单独把文件写入服务器。
- 删除或停用前先查看应用、自动化任务和待执行部署是否仍在使用。
- 页面时间按浏览器本地时间显示；“即将到期”和“已过期”是需要优先处理的提示。
