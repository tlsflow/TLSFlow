# 用户

“用户”页面用于维护可以登录当前租户的人员账号，并查看账号来源、状态、所属租户和角色。

## 创建本地用户

1. 进入“系统设置 → 用户”，确认“用户”标签已选中，点击“创建用户”。
2. 在“创建方式”选择“本地用户”。
3. 填写用户名、显示名、邮箱和初始密码；显示名用于页面和操作记录中识别人员。
4. 在“角色”下拉框选择职责对应的角色。暂时不确定权限时可先选择只读角色，后续再调整。
5. 点击“创建用户”，返回列表后确认状态为“启用”。将用户名和初始密码通过安全渠道交给本人，并提醒首次登录后修改密码。

> [截图占位符：用户列表页，标出“创建用户”按钮、用户/组标签和主要信息列]

## 从身份源添加用户

如果管理员已经配置身份源（例如企业目录），可在创建窗口选择“身份源用户”：

1. 选择身份源，输入目录用户名。
2. 点击“检索用户”，核对返回的姓名、邮箱等资料，确认是正确人员。
3. 选择角色并保存。系统会保留该人员与身份源的关联，后续登录使用企业目录账号。

检索不到用户时，先确认身份源可用、用户名拼写正确，再联系身份源管理员；不要为了绕过检索而建立重复的本地账号。

## 管理用户组

切换到“组”标签可查看用户组。点击“添加组”后，可选择“本地组”填写组名称和编码，也可选择“身份源组”并检索目录组。组可以在“角色”页面一次性获得权限，适合按团队管理访问范围。

> [截图占位符：添加组窗口，标出本地组/身份源组选择和“检索组”按钮]

## 编辑、禁用和删除

- 点击用户行的“编辑”可修改显示名、邮箱、角色和状态。将状态改为“禁用”会阻止新的登录，但保留历史操作记录，适合离职或长期停用场景。
- 删除前先确认该用户没有待处理的审批、部署责任或其他交接事项。删除会移除账号关联的本地凭据和角色分配，删除操作需要再次输入 `DELETE` 确认。
- 可勾选多个用户后批量删除。系统内置管理员账号不能被勾选删除，请只把它用于管理工作，不要作为日常部署账号。

人员职责变化时，建议先调整角色和组成员，再禁用账号，最后到“日志审计”确认变更已经记录。
