# 证书部署

“证书部署”是把已准备好的证书安装到目标系统的操作区，包含“自动化”“工作流模板”和“执行记录”三个页面。

> [截图占位：证书部署菜单及自动化、工作流模板、执行记录入口]

## 一次手工部署的完整流程

1. 在“自动化”或应用资产入口发起部署，选择应用、目标设备和要使用的证书版本。
2. 选择部署方式或工作流，并填写页面要求的连接信息、凭据和输出格式。
3. 点击“预检/Dry Run”，先查看权限、目标可用性、证书匹配和输入是否完整。
4. 如果租户启用了审批，提交后等待有权限的人员批准；未启用审批时可直接执行。
5. 进入执行过程，等待备份、安装、服务刷新和验证全部完成。
6. 打开执行记录确认目标回读结果、证书指纹和最终状态。

> [截图占位：部署计划向导，标出应用、证书版本、目标和预检按钮]

不要直接修改已经生成的执行记录。需要变更时，回到应用资产、凭据、工作流或自动化规则中修改，再创建新的部署计划。

## 使用自动化部署

1. 进入“证书部署 → 自动化”，点击“新建自动化”。
2. 选择触发方式：手工运行、定时运行，或证书产生新版本时自动运行。
3. 选择要部署的应用资产，可按域名、环境、标签或负责人缩小范围。
4. 设置并发数量、失败阈值、是否先执行预检以及是否需要审批。
5. 保存后点击“运行”，或等待设定的时间/事件触发。
6. 到“执行记录”查看每个应用的执行结果和被排除的原因。

证书新版本触发的自动化会使用触发当时的版本。审批期间即使又产生新版本，也不会自动换版本。

## 选择和管理工作流模板

1. 进入“证书部署 → 工作流模板”，按名称、适用平台或状态筛选。
2. 打开模板详情，确认它支持的目标系统、所需输入和是否支持回滚。
3. 在应用资产或部署计划中选择合适的模板版本。
4. 模板更新后，已有计划仍使用创建时选定的版本；新计划才会看到新版本。

## 部署阶段如何判断成功

部署通常会依次完成准备、备份、安装、刷新服务和目标验证。只有“目标回读验证”通过，才算真正部署成功；仅看到“上传完成”不代表服务已经使用新证书。

> [截图占位：执行记录中的步骤进度和目标验证结果]

如果执行超时或状态显示“结果未知”，先登录目标系统或访问业务地址确认当前证书，再决定重试或回滚，避免重复写入。支持回滚时，按执行记录提供的回滚入口操作，并再次确认目标验证结果。
