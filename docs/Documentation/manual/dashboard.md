# 仪表盘

仪表盘是每天开始工作的总览页。这里集中显示证书、应用、设备连接、Gateway、系统资源、执行结果和审计摘要，帮助你先判断“哪里需要处理”，再进入具体页面。

## 先看什么

1. **资源卡片**：查看有效证书、即将到期证书、应用资产、在线 Agent 和在线 Gateway 的数量。
2. **系统资源**：查看 CPU、内存使用率。数值为空时表示暂时没有采样结果，不代表主机故障。
3. **趋势卡片**：关注审计成功率、受管对象健康比例和需要关注的证书数量。
4. **状态热力图**：分别查看证书、资产、Gateway 和应用资产的正常、警告、异常及未知状态。资产栏对应统一设备资产，应用资产栏对应域名、端口和部署目标。将鼠标移到色块上可查看名称、连接状态、版本或到期信息。
5. **最近审计**：确认最近的导入、审批、部署和回滚是否成功；失败项目应进入执行记录查看详情。

## 日常操作步骤

1. 先处理红色或黄色状态，再处理即将到期的证书。
2. 点击资源卡片或热力图中的对象，进入对应详情页核对具体原因。
3. 在“最近审计”中确认相关操作已经完成；不要只根据“已提交”判断目标已经更新。
4. 完成处理后点击“刷新”，确认数量和状态已经变化。刷新只重新读取信息，不会自动执行部署。

## 看不到数据怎么办

- 页面显示暂无对象：先确认当前确实已建立证书、设备或应用资产。
- 某项入口不可用：联系系统管理员处理。
- 状态长时间未知：进入对象详情检查最近通信时间和连接测试结果。
