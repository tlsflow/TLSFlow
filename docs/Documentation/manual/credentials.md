# 凭据

凭据是设备、云账号、插件和工作流共用的安全登录材料。系统会加密保存机密值，列表和历史记录不会显示密码、令牌或私钥明文。

## 新建凭据

1. 进入“系统设置 → 凭据”，点击“新建凭据”。
2. 填写名称，选择凭据类型：用户名与密码、SSH 私钥、Bearer Token、API Key、客户端证书、DNS/云服务凭据，或浏览器临时会话。
3. 选择作用域（全局、团队、区域、主机或插件）。需要限定范围时，再填写作用域标识。
4. 按页面提示填写用户名、密码、令牌或证书内容。API Key 还需要填写发送时使用的 Header/Query 名称。
5. 设置有效期；填写 0 或留空表示长期有效。点击“保存”，返回列表确认状态正常。

> [截图占位符：新建凭据窗口，标出基本信息、作用域和机密信息区域]

保存后，在设备、云账号或工作流的“凭据引用”下拉框中选择该凭据，不要把机密值直接粘贴到普通文本框或变量中。

## 浏览器临时凭据

对于必须网页登录后才能取得的凭据，在列表中找到浏览器临时会话并点击“浏览器获取”：

1. 填写或确认认证地址，选择获取插件，设置会话有效期。
2. 设置临时链接密码（至少 8 位），点击“生成浏览器会话”。
3. 打开生成的浏览器链接，在隔离窗口完成登录；链接和密码只发给实际操作人员。
4. 回到窗口点击“获取凭据”，等待页面显示获取成功后保存。会话关闭、过期或失败时，点击“新建会话”重新操作。

> [截图占位符：浏览器临时凭据窗口，标出认证地址、有效期、临时链接密码和“获取凭据”按钮]

## 编辑、轮换和删除

- 编辑时只在需要更换机密值的槽位输入新值；留空表示继续使用原值。保存后，当前引用会使用新值。
- 删除前打开凭据详情查看“影响范围”。仍被设备、工作流、插件、ACME 证书或云账号引用时，必须先解除引用，页面不会允许直接删除。
- 凭据过期或显示“待处理”时，先修正并保存，确认状态恢复后再重新运行相关任务。已完成的部署记录会保留当时使用的凭据快照，不会被轮换改写。

凭据属于高敏感信息，禁止通过截图、聊天工具或日志传递明文；轮换完成后应同步更新负责人员的交接记录。
