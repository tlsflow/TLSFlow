# 用户手册

本手册完全按当前控制台菜单顺序编排。页面上的“保存”只是保存配置，“执行”才会真正创建任务或对目标发起变更。除非页面明确显示成功，不要把表单提交视为部署完成。

## 当前一级菜单

1. 仪表盘
2. 证书管理
3. 资产中心
4. 证书部署
5. 插件中心
6. 监控分析
7. 日志审计
8. 系统设置

术语说明：租户是数据和权限隔离的工作空间；Agent 是安装在目标主机上的执行程序；凭据是由平台加密保存、供任务引用的登录信息；工作流是按步骤执行的部署方案。

报表入口位于“监控分析”页面中。

## 一次证书更新的推荐顺序

1. 在“资产中心 → 设备”接入 Agent 或无 Agent 目标，完成连接测试和只读发现。
2. 在“证书管理 → 证书资产”导入或申请证书版本，核对域名、链和指纹。
3. 在“资产中心 → 应用资产”把证书绑定到已发现的站点，确认执行方式和页面提示的输入信息。
4. 在“证书部署 → 工作流模板”选择合适版本，或在“自动化”配置触发条件和安全控制。
5. 进入“证书部署 → 执行记录”执行预检、审批、部署、目标回读和必要的回滚。
6. 在“监控分析”和“日志审计”分别确认运行结果与审计证据。

发现事实、部署结果、监控探测和通知投递相互独立；一个页面显示成功不能替代另一个页面的验证。
