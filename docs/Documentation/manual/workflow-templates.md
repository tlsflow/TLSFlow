# 工作流模板

工作流模板是一套可重复使用的证书部署步骤。系统提供的模板可直接使用，管理员也可以导入经过审核的模板；页面只显示当前租户可以使用的已发布版本。

1. 进入“证书部署 → 工作流模板”，按名称、插件或状态筛选。
2. 打开模板详情，确认版本、输入字段、执行位置和回滚支持。
3. 需要导入时使用页面提供的导入入口，等待校验完成后再发布。
4. 在应用资产或部署计划中选择明确的模板版本，不要依赖系统自动替换版本。

模板校验失败会显示结构化错误。模板变更不会修改已经创建的部署计划。

## 来源和工作流类型

模板来源分为“系统模板”和“用户导入模板”。系统模板由平台统一维护，用户导入模板由当前租户负责审核和发布。插件附带的模板通常只能查看，不能直接编辑；不再使用的旧模板应停用并保留操作记录。

模板版本在部署计划创建时固定。发布新版本后，已有计划仍按原版本执行；需要使用新版本时，回到应用资产或自动化设置中主动选择。
