# 快速开始（仪表盘）

仪表盘的“快速开始”是导航快捷入口，不是另一套部署流程。可用动作会根据当前租户已有资源和权限显示或置灰。

## 从零开始的操作

1. 点击“导入证书”或证书入口，选择手工导入并填写证书、私钥和可选中间链。
2. 导入成功后进入“资产中心 → 应用资产”，创建应用资产并选择证书。
3. 按向导选择已有设备，或先安装 Agent/创建无 Agent 设备，再执行发现。
4. 保存应用资产后进入“证书部署”，选择工作流或自动化，执行预检并提交计划。
5. 回到仪表盘确认资源数字变化；具体结果以执行记录和目标回读为准。

如果入口显示“不可用”，先补齐证书、应用资产或权限。快速开始按钮不会绕过审批、Dry Run（只读预检）或凭据校验。
