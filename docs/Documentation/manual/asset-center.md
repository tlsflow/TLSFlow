# 资产中心

资产中心用于准备部署所需的业务对象，主要包含“应用资产”“云账号”“设备”和“Gateway（网络转发入口）”。应用资产描述要保护的业务，设备描述可以执行操作的主机或网络目标，云账号描述云服务连接，Gateway 提供网络转发。

> [截图占位：资产中心四类资源入口]

开始部署前，按“云账号（如需要）→ 设备 → 发现 → 应用资产”的顺序准备对象。

## 四类资源如何区分

| 资源 | 保存的内容 | 什么时候使用 |
| --- | --- | --- |
| 应用资产 | 应用名称、域名、环境、负责人、证书和部署关系 | 创建部署计划、查看业务状态 |
| 设备 | 主机/网络目标、连接方式、健康状态和发现结果 | 提供实际执行位置 |
| 云账号 | 云服务提供商、区域和访问凭据引用 | 连接云平台并发现云资源 |
| Gateway | 网络转发地址和可用状态 | 目标无法直接访问时中转 |

## 推荐准备顺序

1. 云账号（如需要）：先配置云服务连接并通过连接测试。
2. 设备：接入 Agent 或创建无 Agent 连接，完成连接测试。
3. 发现：运行标准发现，确认站点、服务和证书位置等结果。
4. 应用资产：选择业务地址、证书版本和已经发现的可部署目标。
5. 证书部署：完成预检和审批后执行安装。

## 选择目标时的判断

| 模式 | 适用情况 |
| --- | --- |
| 无 Agent 设备 | 只有网络连接或标准发现结果，没有安装 Agent |
| 设备默认能力 | 设备已发现可用的系统/站点，按默认方式执行 |
| 工作流覆盖 | 业务明确要求使用自定义工作流步骤 |
| 独立目标 + 工作流 | 目标不属于某台受管设备，只能用单独的工作流连接 |

发现完成后，应用资产优先使用发现到的地址、端口、服务名和证书位置；除非业务确认有变化，不要重复手工填写。发现结果只代表“读到了目标信息”，仍需在部署预检和目标验证中确认可以真正执行。
