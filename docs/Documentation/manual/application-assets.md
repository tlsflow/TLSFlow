# 应用资产

应用资产代表一项需要保护或更新证书的业务。它把业务名称、访问地址、负责人、证书版本和执行目标放在一起，后续部署都从这里开始。

> 【截图占位：应用资产列表，显示应用名称、环境、证书状态、目标数量和操作按钮】

## 新建应用资产

1. 进入“资产中心 → 应用资产”，点击“新增”或“应用接入”。
2. 填写应用名称、访问域名或 IP、环境（如生产/测试）和负责人。
3. 选择已完成连接测试和发现的设备、站点或目标。没有目标时先去“设备”接入并发现。
4. 选择证书资产和具体版本，再选择目标系统需要的证书格式。
5. 按向导填写验证地址、端口和部署所需的安全凭据，查看自动生成的部署输入。
6. 在确认页核对业务、证书、目标和部署方式，点击“保存”。

> 【截图占位：应用接入向导步骤条，显示业务信息、目标选择、证书选择和确认】
>
> 【截图占位：应用资产确认页，显示证书版本、目标和证书格式】

“保存”只保存业务配置，不会写入目标主机。进入“证书部署”并通过预检、审批（如启用）后才会执行。

## 修改应用资产

1. 在列表打开应用详情，点击“编辑”。
2. 修改业务地址、负责人、目标、证书版本或输出格式。
3. 连接信息变化时，先到设备页面重新测试并发现，再返回保存。
4. 保存后重新打开部署预检，确认新的输入和目标均可用。

已经创建的部署计划仍按创建时的配置执行，不会因为后续编辑而自动改变。

## 删除应用资产

删除前先解除自动化、待执行计划和其他活动绑定。系统会检查引用关系，仍在使用的应用资产无法直接删除。

## 选择部署方式的原则

- 优先选择设备发现结果中明确显示“可用”的目标，不要凭经验手填路径或服务名。
- 如果页面提供“使用工作流覆盖”选项，只在确实需要自定义步骤时使用；否则沿用设备提供的默认能力。
- Agent（管理程序）、Gateway（网络转发入口）、SSH 或 HTTP 只是执行位置或连接方式，不代表具体厂商能力。
- 保存前确认应用只有一个明确的证书来源和一个明确的执行方式，避免同一应用重复部署。
