# 自动化

自动化是按触发器选择应用资产、创建部署计划并执行的规则。

1. 进入“证书部署 → 自动化”，点击“新增自动化”。
2. 填写名称和触发器：外部 API、一次性时间、周期时间或证书新版本事件。
3. 选择全部关联应用资产或指定资产，并添加域名、标签、环境、负责人等条件。
4. 设置单次最大目标数、并发数、Dry Run、审批和失败阈值。
5. 保存后使用“运行”或等待触发，进入“执行记录”查看每个目标的计划和排除原因。

证书新版本事件会固定触发事件产生的证书版本，不会在审批恢复后漂移到更新的版本。自动化规则只创建计划，不会绕过当前租户的权限和部署任务设置。

运行详情会展示触发来源、精确证书版本 ID、审批 ID、投递 ID 和目标排除原因。目标因为没有证书绑定、部署能力、权限或不满足过滤条件被排除时，先修正原对象再重新运行，不要手工修改自动化运行快照。通知投递失败与证书部署结果分开记录，通知失败不会回滚已经完成的部署。

过滤条件按事件来源、证书资产/版本、域名、标签、目标环境和负责人缩小范围；当前比较方式包括等于、不等于、包含任一和包含全部。自动化动作由宿主创建部署计划、执行部署计划或发送通知，不能在自动化规则中嵌入任意脚本。启用审批时，运行先进入待审批，批准后继续原运行，不会重新计算目标或改用后来版本。
