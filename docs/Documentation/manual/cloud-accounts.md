# 云账号

云账号是连接云服务的账号档案，和证书资产、设备资产是不同对象。页面只保存凭据引用，访问密钥等敏感内容请先在“系统设置 → 凭据”中建立。

## 添加云账号

1. 进入“资产中心 → 云账号”，点击“添加云账号”。
2. 第一步“选择 Provider”中选择已启用且可用的云服务提供商。若提供商显示不可用，请联系管理员完成该服务的配置，不要强行继续。
3. 点击“下一步”，在“资产信息”中填写显示名称和可选的账号标识。
4. 在“凭据引用”选择已保存的云服务凭据。不要在账号表单中直接填写访问密钥。
5. 如提供商要求区域、项目等连接参数，在“Endpoint 与元数据”或提供商专属字段中填写；元数据必须是有效的 JSON 对象。
6. 确认摘要中的 Provider、账号和凭据均正确后点击“保存”，回到列表查看状态。

## 查看、编辑和删除

- 列表显示名称、Provider、账号标识、连接范围、状态和更新时间。点击记录可查看只读详情。
- 点击“编辑”可以修改显示名称、账号标识、凭据引用及连接范围；已创建账号的 Provider 不可更换，如需换服务请新建账号。
- 删除前确认没有业务流程仍在使用该账号。删除需要再次输入 `DELETE` 确认，删除后不能恢复账号档案。

云账号能否连接由所选服务和凭据共同决定。状态异常时先检查凭据是否启用、账号标识和区域是否正确，再联系云服务管理员；不要把访问密钥粘贴到普通字段、截图或日志中。
