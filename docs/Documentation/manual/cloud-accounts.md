# 云账号

云账号是平台连接阿里云、华为云等云服务的账号档案。账号记录保存的是凭据引用和连接范围，访问密钥等敏感内容应先在“系统设置 → 凭据”中建立。

## 添加云账号

1. 进入“资产中心 → 云账号”，点击“添加”。
2. 在第 1 步选择已启用的云服务提供商。
3. 点击“下一步”，填写账号显示名称和可选的账号标识。
4. 在“凭据档案”中选择已保存的云服务凭据，不要把访问密钥直接粘贴到账号表单。
5. 查看摘要，确认 Provider、账号名称和凭据无误后点击“保存”；区域、可用区和其他资源由发现动作自动读取。
6. 回到列表查看账号状态，必要时打开详情核对发现结果和更新时间。

## 编辑、查看和删除

- 点击“测试连接”验证账号能否正常连接；测试为只读操作，不会写入云平台。
- 点击“发现资源”读取云平台中的资源。发现完成后，每个可用区会显示为独立设备，设备下按云产品、实例或域名建立对应条目。
- 点击“查看资源”可以查看最近一次发现得到的设备、产品、站点条目及发现时间（按本地时间显示）。
- 点击记录可查看 Provider、账号标识、连接范围、状态、设备、站点数量和更新时间。
- 点击“编辑”可以修改名称、账号标识、凭据和连接范围；已创建账号不能更换 Provider。
- 删除前确认没有应用资产或自动化任务依赖该账号。按页面要求输入确认文字后删除，删除后不能恢复账号档案。

当前已接入的云服务为阿里云 CDN。连接状态由云服务、账号标识、区域和凭据共同决定。出现异常时先检查凭据是否启用、区域是否正确，再联系云服务管理员。不要在截图、备注或聊天中暴露访问密钥。

云账号动作始终使用当前 Provider 最新启用的插件版本，无需在账号上手动指定插件版本。云账号的连接测试和发现调用阿里云公开 API；要确认真实云平台连接成功，请在配置了有效云凭据、可访问外网的环境中单独验收。
