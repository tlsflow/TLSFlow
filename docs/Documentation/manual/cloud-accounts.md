# 云账号

云账号是平台连接阿里云、华为云等云服务的账号档案。账号记录保存的是凭据引用和连接范围，访问密钥等敏感内容应先在“系统设置 → 凭据”中建立。

## 添加云账号

1. 进入“资产中心 → 云账号”，点击“添加”。
2. 在第 1 步选择已启用的云服务提供商；显示不可用时请联系管理员处理。
3. 点击“下一步”，填写账号显示名称和可选的账号标识。
4. 在“凭据档案”中选择已保存的云服务凭据，不要把访问密钥直接粘贴到账号表单。
5. 按提供商要求填写 Endpoint、区域、项目等连接范围；元数据必须是一个有效的 JSON 对象。
6. 查看摘要，确认 Provider、账号名称、凭据和范围无误后点击“保存”。
7. 回到列表查看账号状态，必要时打开详情核对连接范围和更新时间。

## 编辑、查看和删除

- 点击记录可查看 Provider、账号标识、连接范围、状态和更新时间。
- 点击“编辑”可以修改名称、账号标识、凭据和连接范围；已创建账号不能更换 Provider。
- 删除前确认没有应用资产或自动化任务依赖该账号。按页面要求输入确认文字后删除，删除后不能恢复账号档案。

连接状态由云服务、账号标识、区域和凭据共同决定。出现异常时先检查凭据是否启用、区域是否正确，再联系云服务管理员。不要在截图、备注或聊天中暴露访问密钥。
