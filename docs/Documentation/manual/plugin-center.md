# 插件中心

插件为平台提供设备连接、发现、证书处理等扩展能力。插件中心用于查看插件版本和状态，并决定哪些插件可以在设备或应用向导中使用。

## 查找插件

1. 打开“插件中心”，先点击“刷新”获取最新列表。
2. 使用搜索框按名称、产品、能力或标签查找插件。
3. 使用“来源”筛选内置插件或用户插件，使用“状态”筛选有效或无效版本。
4. 点击“详情”查看适用产品、版本、运行位置、可提供的能力和使用限制。

## 启用或停用

1. 在详情中确认插件与目标设备或应用匹配，并确认所需凭据已准备好。
2. 对校验通过且未启用的插件点击“启用”，等待状态变为“已启用”。
3. 不再使用时点击“停用”，确认没有正在运行的任务依赖该插件。
4. 返回设备或应用向导，重新打开列表确认插件已可选或已被移除。

插件版本按版本独立管理。升级不会自动替换已经创建的应用资产；如需使用新版本，请在对应向导中重新选择。状态为无效或待审核的插件不能启用。

## 导入用户插件时的检查

- 仅通过页面提供的导入入口提交插件包，等待校验完成。
- 先核对来源、适用平台、版本和能力，再进行审批和启用。
- 导入、审批、启用、绑定和执行是不同步骤；其中一步失败只影响该插件。
- 插件执行失败时，先检查目标兼容性、连接凭据和设备状态，再决定是否重试。
