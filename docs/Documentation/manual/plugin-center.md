# 插件中心

插件是平台扩展设备发现、证书部署或其他能力的受控包。插件中心只显示当前租户可见的插件版本、来源、状态和能力。

## 使用插件

1. 进入“插件中心”，点击刷新市场，查看内置或用户导入的插件包。
2. 打开详情确认版本、兼容平台、执行位置、输入字段和所需权限。
3. 导入用户插件包时使用统一导入入口，等待包校验和注册完成。
4. 启用插件后，在设备或应用资产向导中选择对应能力，再运行连接测试和发现。

插件版本升级后会形成新的版本，已在使用的应用仍继续使用原版本；需要升级时，要在设备或应用资产中主动切换。插件只能使用页面明确授权的连接和凭据。

导入、审批、启用、绑定和执行是五个独立步骤。导入后先核对插件适用的产品、版本、能力和所需权限，再审批并启用；其中任何一步失败都只影响该插件，不要用管理员权限绕过检查。

刷新插件市场不会改变已经创建的部署计划。插件执行失败时，先检查目标是否兼容、凭据是否可用以及当前账号是否有权限；写入操作超时应先确认目标实际状态，再决定是否重试。

如需了解某个插件的使用方式，请先阅读插件详情中的适用范围和输入说明，再按页面向导操作。
