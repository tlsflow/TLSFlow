# 证书资产

证书资产保存一个域名（或一组域名）的证书资料。每次导入或自动签发都会新增一个版本，旧版本会保留，方便核对和回退。

> 【截图占位：证书资产列表，显示域名、状态、到期时间、来源和版本数量】

## 导入证书（手工上传）

1. 进入“证书管理 → 证书资产”，点击“导入证书”。
2. 在来源选择中选择“手工导入”。如果使用 ACME，请改选 ACME 申请入口。
3. 上传或粘贴服务器证书、匹配的私钥和（如有）中间证书链。
4. 点击“导入”，等待页面提示完成，不要重复提交。
5. 在结果页核对主域名、备用域名、签发者、生效时间、到期时间和状态。
6. 返回列表，打开新版本详情，确认指纹与原证书一致。

> 【截图占位：证书来源选择窗口，标出“手工导入”和“ACME 申请”】
>
> 【截图占位：手工导入表单，标出服务器证书、私钥和中间证书链输入区】

如果证书来自 ACME 或企业 CA，成功签发后也会自动出现在此列表。自动签发的证书同样需要检查域名和到期时间。

## 查看版本、详情和使用关系

1. 在列表点击域名卡片，或点击“详情”。
2. 在版本窗口按关键词、状态和到期时间查看历史版本。
3. 点击某个版本查看域名、有效期、签发者、指纹和证书链。
4. 打开“使用关系”，确认哪些应用、自动化任务或部署计划正在引用它。

> 【截图占位：证书版本窗口，显示版本筛选、状态和到期时间】
>
> 【截图占位：证书详情，显示域名、指纹、证书链和使用关系】

同名证书不一定是同一份材料。更新或重新部署前，以域名集合、到期时间和 SHA-256 指纹三项一起确认。

## 删除过期或误导入版本

1. 打开证书详情，先确认目标版本没有被应用资产、自动化或待执行计划引用。
2. 点击该版本的“删除”，阅读风险提示后再次确认。
3. 删除完成后刷新列表，确认剩余版本仍可正常查看。

删除证书版本不会删除已经写入服务器的历史文件；如需清理服务器文件，请单独执行对应的部署或维护流程。

## 部署前检查清单

- 状态为有效，且到期时间覆盖计划的使用周期。
- 主域名和备用域名包含业务实际访问地址。
- 私钥与叶子证书匹配，证书链完整且顺序正确。
- 需要部署到不同系统时，已在“证书格式配置”准备相应格式。
- 应用资产中选择的版本与本页确认的版本一致。

> 【截图占位：证书版本详情中的指纹、域名和有效期字段】

提示：PFX/P12 和 JKS 需要私钥及密码；P7B/P7C/SPC 只包含证书和链，不包含私钥。导入这类文件时，请另外提供匹配的私钥。
