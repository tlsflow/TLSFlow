# 证书资产

证书资产保存证书的基本信息和多个历史版本。每次导入都会形成一个新版本，旧版本仍可用于核对和回退。

> [截图占位：证书资产列表，显示域名、状态、到期时间和版本数量]

## 导入证书（手工上传）

1. 进入“证书管理 → 证书资产”，点击“导入证书”。
2. 选择证书来源。手工上传时，分别粘贴或上传服务器证书（叶子证书）、匹配的私钥和（如有）中间证书链。
3. 点击“提交/导入”，等待系统解析。不要在解析未完成时重复点击。
4. 在结果中核对主域名、备用域名、签发者、生效时间、到期时间和证书状态。
5. 返回列表确认新版本已出现，并打开详情检查指纹是否与原文件一致。

> [截图占位：导入证书表单，标出证书、私钥和中间链输入区域]

如果证书来自 ACME 或企业 CA，成功签发后也会自动出现在此列表。自动签发的证书同样需要检查域名和到期时间。

## 查看版本和使用关系

1. 在列表点击证书名称或“查看详情”。
2. 在“版本”区域选择要查看的版本，按到期时间或状态筛选。
3. 查看该版本的域名范围、签发者、指纹、证书链和当前状态。
4. 查看“使用关系/应用使用情况”，确认哪些应用资产、自动化任务或部署计划引用了该版本。

> [截图占位：证书详情中的版本列表、证书信息和使用关系]

同名证书不一定是同一份材料。更新或重新部署前，以域名集合、到期时间和 SHA-256 指纹三项一起确认。

## 删除过期或误导入版本

1. 打开证书详情，先确认目标版本没有被应用资产、自动化或待执行计划引用。
2. 点击该版本的“删除”，阅读风险提示后再次确认。
3. 删除完成后刷新列表，确认剩余版本仍可正常查看。

删除证书版本不会删除已经写入服务器的历史文件；如需清理服务器文件，请单独执行对应的部署或维护流程。

## 部署前检查清单

- 状态为有效，且到期时间覆盖计划的使用周期。
- 主域名和备用域名包含业务实际访问地址。
- 私钥与叶子证书匹配，证书链完整且顺序正确。
- 需要部署到不同系统时，已在“证书格式配置”准备相应格式。
- 应用资产中选择的版本与本页确认的版本一致。

> [截图占位：证书版本详情中的指纹、域名和有效期字段]

提示：PFX/P12 和 JKS 需要私钥及密码；P7B/P7C/SPC 只包含证书和链，不包含私钥。导入这类文件时，请另外提供匹配的私钥。
