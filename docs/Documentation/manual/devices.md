# 设备

设备是证书部署的执行位置，可以是安装了 Agent（管理程序）的主机，也可以是通过网络连接的无 Agent 目标。只有连接测试和发现都通过后，应用资产才会显示可部署目标。

> [截图占位：设备列表，显示设备类型、连接方式、健康状态和操作按钮]

## 新增设备并完成发现

1. 进入“资产中心 → 设备”，点击“新增设备”。
2. 选择接入方式：使用已有 Agent、创建无 Agent 连接，或选择页面提供的系统接入方式。
3. 填写管理地址、端口、是否启用 TLS，以及“系统设置 → 凭据”中已保存的凭据。
4. 保存后点击“连接测试”，确认结果为成功。
5. 点击“发现/标准发现”，等待系统读取目标信息。
6. 打开发现结果，检查系统类型、站点、服务名称、证书位置和能力状态。
7. 返回应用资产向导，只选择状态为可用且兼容的目标。

> [截图占位：新增设备向导，标出接入方式、地址、端口、TLS 和凭据字段]

连接测试只说明网络和登录信息可用；发现成功后，页面才会显示可用于部署的站点和服务。

## 查看设备详情

点击设备名称可查看基本信息、当前健康状态、Agent 在线情况、已发现的系统/站点/服务、证书文件位置、关联应用数量和最近操作记录。

> [截图占位：设备详情中的概览、站点、证书和日志标签页]

## 常见问题处理

- 连接测试失败：检查地址、端口、TLS 证书校验和凭据是否正确，再重新测试。
- 发现有警告：先查看缺少的站点、服务或证书位置；补齐设备信息后重新发现。
- 设备在线但不可部署：确认目标兼容性和能力状态，不要仅凭在线状态创建部署。
- Agent 需要升级：在设备列表的升级入口查看目标版本，确认后再执行升级。
- Gateway 设备：Gateway（网络转发入口）只负责转发连接，不能替代可执行证书操作的完整设备。

发现成功不等于证书已经部署。真正完成还要经过部署预检、安装和目标回读验证。
