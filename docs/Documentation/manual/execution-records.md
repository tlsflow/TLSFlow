# 执行记录

1. 进入“证书部署 → 执行记录”，按状态、应用资产、任务编号或时间筛选。
2. 打开记录查看预检结果、审批状态、每个步骤的输出摘要和目标验证结果。
3. “待审批”记录先完成审批；“失败”记录查看第一个失败步骤和错误提示。
4. 目标支持回滚时，确认恢复快照和当前目标状态后执行回滚；回滚结果仍需回读验证。
5. 任务卡住时使用取消或强制取消，不要直接删除记录。

执行记录里的密码、私钥和证书材料只显示脱敏引用。历史记录不能编辑，重试会生成一条新的记录。

记录状态应按“预检 → 待审批 → 执行中 → 验证 → 成功/失败/状态待确认”理解。“状态待确认”表示目标的最终结果还没有被平台确认，不等同于失败；先登录目标系统或查看服务状态，再决定补偿或回滚。回滚成功后仍需重新打开应用或检查证书，确认用户实际访问正常。
