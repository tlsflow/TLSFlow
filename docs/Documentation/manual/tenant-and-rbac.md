# 租户与 RBAC

租户是人员、设备、证书和应用资产的隔离空间；角色决定成员可以查看、修改、审批或执行哪些工作。先规划租户和岗位，再邀请人员进入日常操作。

## 初始化一个租户

1. 使用初始管理员登录，确认顶部租户名称正确。
2. 打开“系统设置 → 角色”，按岗位创建角色，例如只读查看、证书管理、部署审批和审计查看。
3. 打开“系统设置 → 用户”，创建本地账号或绑定身份源账号，并为每位人员分配岗位角色。
4. 需要按团队授权时，先在“用户 → 组”创建团队，再把团队加入对应角色。
5. 使用一个普通岗位账号重新登录，验证它能看到的菜单和可执行的操作是否符合预期。

## 管理租户层级

在“系统设置 → 租户架构”查看当前是单租户还是分层模式。切换前先运行页面检查，逐项处理阻塞项，再在维护窗口确认。分层模式下可以新增公司节点、指定管理员以及暂停或恢复节点；这些操作会同时影响该节点下的人员和资源，操作前应保留审批记录。

## 变更权限后的检查

- 同一人员可拥有多个角色；权限范围按系统最终计算结果执行。
- 角色、组成员或账号状态改变后，让相关人员重新登录。
- 到“日志审计”确认权限变更已记录，并用实际业务账号复核证书查看、应用管理、部署审批和日志查看。
- 证书私密材料、凭据管理、插件启用、审批和部署执行尽量分属不同岗位，避免单个账号拥有全部高风险操作。
