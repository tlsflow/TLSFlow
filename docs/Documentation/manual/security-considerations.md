# 安全注意事项

以下内容面向日常管理员和运维人员，目标是避免账号、证书和连接材料被误用或泄露。

## 账号与权限

- 每个人使用独立账号，按岗位分配最小角色；不要共享管理员账号。
- 人员离职或职责变化时，先移除角色和组成员，再禁用账号，并检查审计记录。
- 把凭据管理、插件启用、证书高风险操作、审批和部署执行分给不同岗位；菜单隐藏不能代替权限控制。

## 凭据与证书

- 密码、API Token、SSH 私钥、客户端证书、PFX/JKS 密码和 Webhook 密钥只通过“系统设置 → 凭据”保存和引用。
- 不要把机密值写入工作流说明、普通备注、截图、聊天记录或日志。轮换后立即通知使用该凭据的责任人。
- 浏览器临时会话使用短有效期和一次性分享密码，登录完成后及时关闭会话。

## 网络与外部连接

- 生产环境通过 HTTPS 访问管理界面，并限制可访问的人员和网络范围。
- 浏览器临时窗口和内部服务只允许通过平台提供的页面访问，不要把内部调试或远程控制端口直接暴露到公网。
- Webhook、DNS 服务和目标主机按租户网络策略放行；不要为了“先跑通”长期关闭证书校验。

## 审计与异常处理

- 定期查看“日志审计”和执行记录，确认账号、角色、凭据、审批、部署和回滚操作均有责任人。
- 外部连接结果显示“未知”或超时时，先到目标服务确认实际状态，再决定重试、补偿或回滚，避免重复执行。
- 备份应包含数据库、工作流、插件和恢复所需的密钥，并定期在隔离环境演练恢复；备份文件本身也要限制访问。
