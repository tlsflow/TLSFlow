# 日志审计

日志审计记录平台中的关键操作，帮助你确认谁在什么时候对哪个对象执行了什么操作，以及操作是否成功。它适合日常复核、权限追踪、变更留档和问题交接。

## 查找一条操作记录

1. 进入“日志审计”，先查看顶部的记录总数、失败数量、用户操作数量和成功数量。
2. 使用关键词搜索对象名称、操作人或事件摘要，按时间倒序查看结果。
3. 点击“查看详情”阅读完整摘要、事件类型、关联对象和发生时间。页面时间按浏览器本地时间显示。
4. 对“失败”或“拒绝”记录记下操作人、对象名称和关联编号，再到执行记录或对应业务页面继续处理。
5. 刚完成部署、审批或权限变更后点击“刷新”，确认审计事件已经写入。


## 导出操作证据

1. 点击页面右上角“导出操作证据”。
2. 等待页面返回导出结果；如果出现失败提示，先记录提示中的请求编号，再联系管理员处理。
3. 导出的内容用于审计留档和问题交接，建议与对应的部署计划、执行记录或报表一并保存。


## 常见核对场景

- **登录与会话**：核对登录成功、登录失败和退出时间，确认账号使用符合值班安排。
- **权限和审批**：核对角色调整、权限拒绝、审批创建、通过或驳回，确认变更是否经过授权。
- **证书和部署**：核对证书导入、创建部署计划、执行部署和请求回滚，确认操作人与业务工单一致。
- **插件和工作流**：核对插件安装、权限拒绝和工作流执行，确认使用的是批准过的能力。
- **通知与自动化**：结合自动化运行和通知投递记录，确认失败究竟发生在目标选择、部署执行还是消息发送。

排查时把执行记录中的计划编号、运行编号与审计摘要中的关联编号放在一起核对，不要只根据单条日志做结论。

## 安全与隐私提示

审计记录只提供查看和导出，不提供编辑或删除入口。凭据、私钥、令牌和 Secret 只显示脱敏信息；导出文件和截图仍应按组织的审计资料权限保存，不要把审计截图当作凭据备份。
