# 仪表盘

仪表盘是每天开始工作的总览页。它把证书、应用、资产连接、Gateway、系统资源、执行结果和审计活动汇总到一页，帮助你先定位需要处理的事项，再进入详情页完成操作。

## 页面信息怎么读

- **核心指标**：显示有效证书、临近到期证书、应用、在线 Agent 和在线 Gateway 的数量。点击指标可进入对应列表。
- **系统资源**：显示仪表盘主机的 CPU 和内存使用率。暂时没有数值表示尚未采样，不等同于主机故障。
- **运行趋势**：观察审计操作成功率、受管对象健康度和证书到期关注项，适合判断整体变化。
- **资产状态**：按证书、资产、Gateway 和应用资产分组显示正常、关注、异常或未知状态。将鼠标移到色块上可查看对象名称及状态详情。
- **最近审计日志**：优先展示失败、拒绝、高风险和关键变更。需要了解失败原因时，打开对应的执行记录或对象详情。


## 推荐的日常检查顺序

1. 先处理“异常”和“关注”状态，再处理临近到期证书。
2. 点击对应指标或状态色块，打开对象详情并阅读原因说明。
3. 对需要变更的应用进入“证书部署”，检查页面提示后提交执行；不要把“已提交”当作目标已更新。
4. 在最近审计日志和执行记录中确认任务完成、目标回读及验证结果。
5. 处理结束后点击“刷新”确认数据变化。刷新只重新读取信息，不会自动执行部署。

## 页面显示为空或状态未知

- **暂无对象**：当前租户还没有相应证书、资产或应用，先完成资产接入。
- **指标没有变化**：刷新页面并检查筛选条件；后台任务完成后数据才会更新。
- **状态长时间未知**：进入对象详情，检查最近心跳、连接测试和发现时间。
- **入口不可用**：通常是权限或前置配置不足，请联系管理员确认租户权限和插件状态。

仪表盘用于发现问题，不替代执行记录、目标验证和审计日志。涉及证书变更时，请始终以这些页面的最终结果为准。
