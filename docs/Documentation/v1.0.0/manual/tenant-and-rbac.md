# 租户与 RBAC

租户是人员、设备、证书和应用资产的隔离边界；RBAC（基于角色的访问控制）决定成员可以查看、编辑、审批或执行哪些操作。建议先确定组织边界，再安排角色和成员。

## 规划权限

- 用租户区分需要隔离的公司、团队或环境。
- 用角色描述岗位职责，例如只读查看、证书管理、部署审批和审计查看。
- 用用户组按团队批量授予角色，避免逐人维护相同权限。
- 高风险能力（凭据、插件、审批、部署执行）尽量分配给不同岗位。

## 查看和切换租户架构

进入“系统设置 → 租户架构”查看当前是单租户还是分层模式。分层模式启用前，先查看现有数据并处理所有阻塞项，再在维护窗口选择“启用”。需要恢复单租户时，使用“回滚”并保留审批记录。


## 创建公司节点和管理员

在分层模式下：

1. 在“创建公司节点”表单填写名称、编码和上级节点，选择“创建”。
2. 在“添加管理员”表单选择公司节点，输入用户主体 ID，选择“添加”。
3. 在树状列表核对节点状态、当前租户和管理员。误配时选择“撤销管理员”。
4. 需要暂时停用节点时选择“暂停”；确认恢复条件后选择“恢复”。节点状态会影响其下成员和资源的使用。

## 分配角色并验证

1. 到“系统设置 → 角色”创建或调整角色，再到“系统设置 → 用户”分配给用户或组。
2. 让相关人员重新登录，使新的成员关系生效。
3. 使用实际岗位账号验证证书查看、资产编辑、部署审批和日志查看等关键操作。
4. 到“日志审计”确认角色、组成员、租户管理员和节点状态变更均已留痕。

同一人员可以拥有多个角色，最终权限由系统合并计算；不要仅凭菜单是否显示判断授权结果。
