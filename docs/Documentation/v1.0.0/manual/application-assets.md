# 应用资产

应用资产代表一个需要保护或更新证书的网站、API 或其他 TLS 服务。它把访问地址、环境、证书和部署目标放在一起，后续的部署和回滚都以此为依据。


## 新建应用资产

1. 进入“资产中心 → 应用”，点击“添加应用”。
2. 填写应用地址、端口和环境；需要时补充显示名称、验证 URL 和负责人。
3. 在“证书要更新到哪里？”中选择已完成连接测试和发现的设备、服务及部署目标。没有目标时，先返回资产中心接入并发现目标。
4. 选择证书资产和版本，并按目标系统要求选择证书格式。
5. 按页面提示补充部署凭据和其他输入，检查向导生成的部署信息。
6. 在确认页核对地址、证书版本、目标和执行方式，点击“保存”。

“保存”只保存应用配置，不会写入目标主机。进入“证书部署”检查页面提示并提交后，审批（如启用）通过才会执行。

## 修改应用资产

1. 在列表打开应用详情，点击“编辑”。
2. 修改访问地址、端口、负责人、目标、证书版本或证书格式。
3. 连接信息变化时，先到资产中心重新测试并发现，再返回保存。
4. 保存后重新打开证书部署页面，确认新的输入和目标均可用。

已经创建的部署计划仍按创建时的配置执行，不会因为后续编辑而自动改变。

## 删除应用资产

删除前先解除自动化、待执行计划和其他活动绑定。系统会检查引用关系，仍在使用的应用资产无法直接删除。

## 选择部署方式的原则

- 优先选择发现结果中明确显示“可用”的目标，不要凭经验手填路径或服务名。
- 只有确实需要自定义步骤时才选择“工作流覆盖执行”；一般场景优先使用目标提供的默认能力。
- Agent 是目标主机上的管理程序，Gateway 是网络转发节点；SSH、HTTP 等是连接方式，不代表具体厂商能力。
- 保存前确认应用只有一个明确的证书来源和执行方式，避免同一应用重复部署。


## 手动部署更新

- 应用资产保存后，回到应用卡片或列表行，点击“部署更新”选择要部署的证书版本。
- 提交前修正页面列出的凭据、格式或连接问题。
- 部署完成后查看执行记录、目标回读和快照；需要恢复时，从应用详情的快照发起回滚。
