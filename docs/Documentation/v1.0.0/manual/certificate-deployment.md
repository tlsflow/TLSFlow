# 证书部署

“证书部署”负责把应用资产中选定的证书安装到目标系统，并留下可审计的执行记录。页面包含“自动化”“工作流模板”和“执行记录”三个入口。


## 从应用页面手动部署一次

1. 进入“资产中心 → 应用”，找到要更新的应用卡片或列表行。
2. 点击应用上的“部署更新”按钮，打开该应用的证书更新窗口。
3. 选择要部署的证书版本，确认页面显示的目标、连接凭据、证书格式和其他输入均正确；缺少信息时先回到应用资产补齐。
4. 点击“部署此证书版本”提交更新。系统会为这次更新创建部署计划并开始执行；启用审批时，任务会先停留在待审批状态，审批通过后才会连接目标。
5. 执行过程中依次关注备份、安装、服务刷新和目标验证状态。
6. 打开执行记录，确认目标回读的证书指纹和最终状态。


“保存”只保存计划，“执行”才会对目标产生变更。执行记录生成后不要直接修改；需要变更时，修改应用资产、凭据、格式或工作流后创建新计划。

## 创建自动更新计划

“证书部署 → 自动化”只用于创建自动执行证书更新的计划，不是手工部署入口。计划可以按证书产生新版本、指定时间或其他页面提供的触发条件自动运行。

1. 选择触发方式和要覆盖的应用资产。
2. 设置并发数、失败阈值以及是否需要审批。
3. 保存自动化计划，等待配置的时间或事件触发。
4. 在运行历史和执行记录中逐项查看成功、失败和被排除的应用及原因。

由新证书版本触发的自动化会固定使用触发时选中的版本。审批期间产生的新版本不会自动替换当前任务中的版本。

## 选择工作流模板

工作流模板描述目标系统上的执行步骤。选择模板前打开详情，确认适用平台、所需输入、是否支持回滚以及模板版本。模板更新不会改变已有计划；新计划才会使用新版本。

## 判断是否真正成功

只有“目标回读验证”通过，才表示目标服务已经使用新证书。上传或安装完成只能说明文件写入成功，不能替代服务验证。


如果任务超时或显示“结果未知”，先从业务地址或目标系统确认当前证书，再决定重试或回滚。支持回滚时，使用执行记录提供的回滚入口，并再次执行目标验证。
