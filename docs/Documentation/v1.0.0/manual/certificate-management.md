# 证书管理

“证书管理”用于准备证书、维护签发来源和生成部署所需的证书格式。这里完成的是材料准备，不会自动把证书写入服务器。

| 页面 | 适合处理的问题 |
| --- | --- |
| 证书资产 | 导入证书、查看版本、确认指纹和使用关系 |
| ACME 自动化 | 配置 ACME 提供商，申请和续签证书 |
| CA 操作 | 查看 CA 观测数据、同步记录和 CA 状态 |
| 证书格式配置 | 为 PEM、PFX、JKS、P7B 或 DER 生成部署输出配置 |


## 推荐工作流

1. 在“证书资产”导入已有证书，或在“ACME 自动化”创建申请。
2. 如果使用企业 CA，在“CA 操作”确认 CA 状态和同步结果。
3. 在证书详情中创建目标系统需要的格式配置，并确认密码凭据可用。
4. 前往“资产中心 → 应用资产”，把证书版本绑定到业务和可执行目标。
5. 在“证书部署”中检查页面提示并提交；启用审批时，审批通过后再执行。
6. 在“执行记录”确认目标回读结果，在“监控分析”和“日志审计”完成运行验证。

每一步都有独立的完成标志：导入成功不等于可部署，提交成功不等于服务已切换，上传完成也不等于目标正在使用新证书。

## 选择哪个页面

- 已经拿到证书文件：从“证书资产”开始。
- 希望自动申请或续签：从“ACME 自动化”开始。
- 需要查看 AD CS 或内部 CA 的对象和观测：打开“CA 操作”。
- 目标系统要求特定文件格式：在证书版本详情中打开“格式配置”。

格式配置只描述如何生成部署材料；真正的目标选择、页面校验、审批和安装都在证书部署流程中完成。

## 使用时请记住

- 同一域名可以有多个版本，部署前始终核对域名、有效期和 SHA-256 指纹。
- 涉及私钥的导出会读取已保存的安全凭据；不要在工单、聊天或截图中传递私钥和密码。
- 停用提供商、CA 或删除证书前，先检查使用关系和待执行任务。
- 页面中的时间按浏览器本地时间显示；“即将到期”和“已过期”需要优先处理。
