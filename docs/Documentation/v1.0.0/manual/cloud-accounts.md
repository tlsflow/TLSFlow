# 云服务资产

云服务资产用于把云厂商账号或服务接入 TLSFlow，并从云平台读取可管理的资源。它与服务器、网络设备一样显示在“资产中心 → 资产”，但不代表一台主机，也不会自动创建证书部署计划。

当前正式验收的云服务对象为阿里云 CDN。其他云厂商或产品只有在完成实际连接、资源发现和审计验收后，才可视为正式支持；插件目录中的其他条目不等于可用于生产。


## 接入前准备

- 在“系统设置 → 凭据”创建与云厂商和 Provider 匹配的“云 Provider 凭据”，并确认状态为“启用”。
- 确认 TLSFlow 所在环境可以访问云厂商 API，且账号具备读取目标资源所需的最小权限。
- 准备一个清晰的资产显示名称，例如“阿里云 CDN · 生产账号”。显示名称用于识别资产，不是云厂商账号名的替代品。

## 添加云服务资产

1. 打开“资产中心 → 资产”，点击“添加资产”。
2. 在平台列表中选择需要接入的云服务 Provider。页面只显示已启用且凭据字段完整的 Provider。
3. 填写资产显示名称，选择或填写 Provider 要求的凭据引用和其他字段。
4. 提交后等待连接测试和资源发现完成。连接测试只读，不会修改云平台配置。
5. 返回资产列表，打开详情确认 Provider、产品、区域/范围、站点数量和最近发现时间。


接入过程中不选择证书、不创建应用资产，也不执行证书部署。发现到的资源要用于证书业务时，请回到“资产中心 → 应用”按应用接入流程选择目标。

## 查看和重新发现

点击云服务资产的“查看详情”，可查看：

- Provider 和产品族；
- 账号或服务的区域/覆盖范围；
- 已发现的 Framework、站点和可用目标数量；
- 插件版本、发现状态和最近发现时间。

在详情窗口点击“重新发现”可刷新云平台资源。刷新期间不会更换凭据或修改云平台配置；完成后以详情页显示的最新结果为准。


阿里云 CDN 的发现结果会按“中国大陆”和“国际站”覆盖范围分组展示。分组名称表示资源覆盖范围，不代表两个独立账号；实际站点以云平台返回结果为准。

## 编辑和删除

- 可编辑云服务资产的显示名称、凭据引用和页面允许修改的连接信息；更换 Provider 不在已创建资产上进行。需要更换 Provider 时，请新建资产并完成一次连接测试和发现。
- 修改凭据后，重新发现前先在“系统设置 → 凭据”确认新凭据已启用，并检查有效性检测结果。
- 删除前确认没有应用资产、自动化任务或其他业务流程依赖该云服务资产。按页面要求输入确认文字后删除，删除的资产记录不能恢复。

## 常见问题

**平台列表中没有需要的 Provider**
确认管理员已启用对应插件版本，且插件声明的凭据字段可以正常加载。目录或测试 Fixture 不代表 Provider 已正式支持。

**连接测试失败**
检查云 API 网络连通性、凭据类型和状态、Provider 是否匹配，以及账号权限是否足够。修正后重新编辑并提交，或在详情页重新发现。

**连接成功但资源数量为零**
确认账号作用域、区域和产品权限。TLSFlow 只展示云 API 实际返回且通过资源校验的内容，不会根据账号名称猜测资源。

**发现结果过期**
在详情页执行“重新发现”。重新发现仍失败时，先查看错误信息和凭据有效性，再联系云服务管理员。

云服务插件只负责连接测试和资源发现；证书签发、部署、验证和回滚请使用证书管理、应用资产和证书部署中的相应流程。
