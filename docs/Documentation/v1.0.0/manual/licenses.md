# 许可证

打开“系统设置 → 许可证”可以查看当前套餐、授权状态、有效期、版本兼容性、应用资产额度、并发执行额度、插件额度和已启用功能。状态可能为未配置、有效、宽限期、已过期、已撤销或检测到时间异常。


## 查看授权状态

打开页面后点击“刷新”，确认显示的套餐和有效期与采购记录一致。页面中的“升级”只打开版本和功能对比，不会直接改变当前授权。

重点关注：

- **版本兼容性**：许可证是否适用于当前产品版本。
- **应用资产额度**：已使用数量和可用上限；达到上限后无法继续创建受限资产。
- **并发执行和插件额度**：影响同时运行的任务数和可启用插件数。
- **完整性提示**：出现签名校验失败或篡改提示时，应停止导入并联系授权方。

## 离线激活

1. 点击“导出离线请求”，将下载的 JSON 文件保存到受控位置。
2. 把文件交给授权方处理。不要修改内容，也不要上传到公开存储或聊天工具。
3. 收到授权方返回的许可证或激活响应后，点击“导入许可证”，选择 JSON 文件；也可以把完整 JSON 粘贴到文本框后导入。
4. 导入成功后点击“刷新”，确认状态、有效期和版本兼容性均符合预期。


许可证和激活响应必须由授权方生成。签名校验失败、安装标识不匹配或许可证被撤销时，不要手工编辑 JSON，请重新获取文件。导入许可证不会改变用户、应用资产或历史执行记录。
