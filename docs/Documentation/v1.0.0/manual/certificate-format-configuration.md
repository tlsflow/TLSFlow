# 证书格式配置

格式配置决定部署时生成哪一种证书制品。它不是证书本身，也不会单独触发部署；只有在应用资产或工作流中被选中时，平台才会按配置生成文件。


## 创建配置

1. 打开“证书管理 → 证书资产”，进入目标证书版本详情，选择“格式配置”。
2. 选择输出格式：`PEM`、`PFX / PKCS#12`、`JKS`、`P7B / PKCS#7` 或 `DER`。
3. 如需将配置绑定到特定版本，填写证书版本 ID；留空可创建可复用的通用模板（若当前页面提供该选项）。
4. 设置是否包含私钥。`PFX` 和 `JKS` 必须包含私钥；`DER` 和 `P7B` 不能包含私钥。
5. 对 `PFX` 或 `JKS` 选择密码凭据；需要 Java 密钥库别名时填写 alias。
6. 点击“创建”，回到列表确认状态可用。


页面显示的密码字段是凭据引用，不会回显明文密码。没有匹配的私钥或密码凭据时，配置可以保存，但提交部署或生成制品时会失败。

## 格式选择建议

| 格式 | 常见目标 | 生成前必须确认 |
| --- | --- | --- |
| PEM | Nginx、Apache 和多数 Linux 服务 | 证书链顺序正确；按目标需要包含私钥文件 |
| PFX / PKCS#12 | Windows、网关和部分中间件 | 有匹配私钥、密码凭据和 alias（如目标要求） |
| JKS | Java 应用服务器 | 有匹配私钥、密码凭据和 alias |
| P7B / PKCS#7 | 只需要证书链的导入场景 | 不含私钥，不能单独完成 HTTPS 配置 |
| DER | 需要二进制单证书的系统 | 不含私钥，确认目标接受 DER 编码 |

## 在部署中使用

1. 在“资产中心 → 应用资产”编辑应用，选择证书版本和格式配置。
2. 保存后进入证书部署页面，确认生成的文件格式、文件名和凭据引用符合目标要求。
3. 检查页面提示后提交执行或审批。

修改格式配置只影响之后创建的部署计划。已经创建的计划会保留创建时的配置快照；如需使用新规则，请重新创建计划。

## 修改和删除

编辑配置前先确认没有正在执行的任务依赖它。删除前检查使用关系；系统会阻止删除仍被引用的配置。修改或删除配置不会清理服务器上已经生成的历史文件。
