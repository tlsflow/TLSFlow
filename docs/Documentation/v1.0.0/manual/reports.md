# 报表

报表把证书、风险和自动化运行数据汇总为可筛选、可导出的管理视图，适合周报、复盘和风险跟踪。报表是统计结果，不能替代单个执行记录、审计记录或站点实测结果。

## 选择报表

当前提供三类报表：

| 报表 | 适合回答的问题 |
| --- | --- |
| 证书事故窗口 | 哪些证书即将到期或已过期，是否缺少替换证书、部署计划或执行通道？ |
| 风险处置 | 风险是否及时确认和解决，是否有重新打开或超过处理时限的情况？ |
| 自动化成效 | 自动化运行和目标的成功率如何，失败集中在哪个阶段，是否发生重试、回滚或人工介入？ |

从“监控分析 → 报表”打开对应页面。

## 设置时间范围和筛选条件

1. 在页面顶部选择“最近 7 天”“最近 30 天”或“最近 90 天”。切换范围后，系统会自动重新加载数据。
2. 在筛选区填写环境、负责人、应用资产、标签等通用条件。
3. 风险处置报表还可以按严重程度和风险类型筛选。
4. 自动化成效报表还可以按自动化编号和失败阶段筛选（目标选择、计划创建、审批、执行、验证、回滚或通知）。
5. 点击“应用筛选”查看结果；需要重新开始时点击“重置筛选”。


## 阅读报表结果

1. 先看指标卡片，了解总量、成功率、逾期数量或平均处理时长。点击某张指标卡片可进入该指标的对象下钻。
2. 在“历史趋势”中查看每日快照数量和数据完整性。显示“不完整”时，先把它当作数据范围提示，不要直接与完整周期比较。
3. 在“分组对比”中按环境、负责人、严重程度、风险类型或失败阶段比较数量，找出需要优先处理的群组。
4. 在“对象下钻”中查看具体证书、资产、自动化运行或部署计划。表格中的时间按浏览器本地时间显示。


## 导出和留档

1. 确认筛选条件和指标已经符合本次汇报范围，点击右上角“导出 CSV”。
2. 等待生成完成后，点击导出历史中的“下载”保存文件；生成中的记录会显示排队或处理中状态。
3. 导出失败或已过期时，先确认时间范围和筛选条件，再重新生成，不要把失败文件当作正式数据。
4. 对账或审计时，同时保存报表运行记录和 CSV 文件，方便追溯本次统计口径。


## 使用边界

报表是按选定时间和筛选条件生成的汇总，不会修改证书、风险或自动化状态。发现异常数字时，回到对应的执行记录、监控探测历史或日志审计核对原始事实。时间范围和筛选条件越窄，结果越适合定位问题；对外汇报前请明确统计周期和统计范围。
