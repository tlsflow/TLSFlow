# 凭据

凭据是 TLSFlow 为设备、插件、工作流、ACME 证书和云服务保存的登录材料。系统只保存加密后的机密值，列表、详情和审计记录不会显示密码、私钥或令牌明文。

入口：**系统设置 → 凭据**。


## 创建凭据

1. 打开“系统设置 → 凭据”，点击“新建凭据”。
2. 输入便于识别的名称，选择凭据类型：密码、用户名与密码、SSH 私钥、Bearer Token、API Key、客户端证书、DNS Provider、云服务 Provider 或浏览器临时会话。
3. 选择作用域。全局凭据可供当前租户按权限使用；团队、区域、主机和插件作用域用于缩小可见范围。选择非全局作用域时必须填写对应标识。
4. 按页面提示填写用户名、密码、私钥、令牌或证书。API Key 还要指定发送位置（Header、Query 或 Cookie）及名称。
5. 设置有效期。留空或填写 0 表示长期有效；浏览器临时会话还可以分别填写天、小时和分钟。
6. 点击“保存”，返回列表确认状态为正常。


保存后，在设备、云服务或工作流的“凭据引用”中选择这条记录。不要把密码或 Token 粘贴到普通文本框、工作流变量、截图或日志中。

### 云服务凭据

选择“云 Provider 凭据”后，页面会加载已启用插件声明的字段，例如访问密钥或签名密钥。只填写页面列出的字段；如果没有可用的云服务插件或字段合同，先联系管理员启用正确版本的插件。云服务资产必须引用与 Provider 匹配且状态为“启用”的凭据。

### DNS Provider 凭据

选择 DNS Provider 后，从列表选择对应的 DNS 服务，并在机密信息区域填写服务要求的配置。该凭据主要用于 ACME DNS-01 验证，不要把 DNS 服务密钥当作普通设备密码使用。

## 浏览器临时凭据

当服务必须通过网页登录后才能取得 Cookie、Token 或其他会话信息时，可以使用浏览器临时会话：

1. 在凭据列表找到类型为“浏览器临时会话”的记录，点击“浏览器获取”。
2. 确认认证地址 URL，选择获取插件，设置会话有效期（60 至 3600 秒）。
3. 设置 8 至 128 位临时链接密码，或点击“随机生成”。链接和密码只发送给实际登录人员。
4. 打开生成的浏览器链接，在隔离窗口完成登录。不要在此窗口处理与当前服务无关的账号。
5. 返回 TLSFlow，等待会话进入可获取状态，点击“获取凭据”。页面显示保存成功后，再关闭会话。
6. 会话过期、关闭或失败时，点击“新建会话”重新操作；不要继续使用旧链接。


临时会话只允许已发布插件工作流执行声明的提取和验证动作。TLSFlow 不会把浏览器运行时端口直接暴露给用户。

## 编辑、轮换和停用

- 编辑凭据前先查看“影响范围”。保存新的机密值后，仍在引用这条凭据的资源会立即使用新值。
- 编辑时，机密字段留空表示保留原密文；只有确实需要更换的字段才输入新值。
- 凭据过期、状态为“待处理”或有效性检测报错时，先修正凭据并保存，再重新运行相关连接或部署任务。
- 需要临时阻止使用时，在编辑窗口点击“停用”；恢复使用时点击“启用”。停用不会删除已保存的机密值。
- 已完成的执行记录会保留当时使用的凭据版本，不会因为后续轮换而被改写。

## 有效性检测

有效性检测用于确认凭据能否通过关联设备的实际认证，默认关闭，不等同于部署验证。

1. 打开凭据的有效性检测详情，查看关联设备、最近检测时间和结果。
2. 点击“手动检测”立即提交一次检测。检测只使用一台在线且支持凭据测试的设备。
3. 如需定期检测，在编辑凭据时启用“定期有效性检测”，选择可用设备；在“配置”中设置当前租户的检测间隔（默认 720 分钟，可设置 1 至 43200 分钟）。
4. 根据结果处理：`有效` 表示认证通过，`不可达` 表示网络或设备状态异常，`错误` 表示凭据或插件处理失败，`未使用` 表示当前没有检测记录。


## 删除凭据

打开凭据的删除窗口，先检查影响范围。只要仍被设备、工作流、插件、ACME 证书、云服务资产或浏览器会话引用，系统就会禁止删除；请先解除引用或更换引用。删除没有引用的凭据后，相关加密数据也会被清理，不能恢复。

## 安全建议

- 为不同环境和用途创建独立凭据，避免一条高权限凭据被多个系统共用。
- 采用最小权限和最短有效期；轮换后及时通知负责人员，并确认连接测试通过。
- 临时链接密码和云厂商访问密钥应通过受控渠道传递，禁止写入截图、聊天记录、工作流模板和日志。
- 发现凭据泄露时，立即在服务端停用并轮换，同时检查影响范围和相关执行记录。
