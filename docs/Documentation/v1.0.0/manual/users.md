# 用户

“系统设置 → 用户”用于维护当前租户的登录人员和用户组。页面会同时显示账号来源、状态、邮箱、角色和所属租户；权限本身在“角色”页面定义。

## 创建本地用户

1. 选择“用户”页签，点击“创建用户”。
2. 将创建方式设为“本地用户”，填写用户名、显示名、邮箱和初始密码。
3. 按职责选择角色。还未确定职责时，先授予只读角色，确认工作范围后再调整。
4. 选择“创建用户”，返回列表确认账号状态。通过安全渠道把初始登录信息交给本人，并要求首次登录后修改密码。


## 从身份源添加用户

管理员已配置身份源（例如企业目录）时，可在创建窗口选择“身份源用户”：

1. 选择身份源并输入目录用户名。
2. 选择“检索用户”，核对返回的姓名和邮箱，确认不是同名账号。
3. 选择角色并保存。以后该人员使用企业目录账号登录，TLSFlow 保留与身份源的关联。

检索不到用户时，先确认身份源状态和用户名拼写，再联系身份源管理员。不要为了绕过检索而建立重复的本地账号。

## 管理用户组

在“组”页签选择“添加组”：

- **本地组**：填写组名称和编码。
- **身份源组**：选择身份源，输入目录组名称并检索，确认返回的组资料后保存。

之后可以在“角色”页面把角色授予组，适合按团队统一维护权限。


## 编辑、停用和删除

- 选择用户行的“编辑”可修改显示名、邮箱、角色和状态。**禁用**会阻止新的登录，但保留历史操作记录，适合离职或长期停用。
- 删除前确认没有待处理的审批、部署责任或交接事项。删除需要再次输入 `DELETE`；可勾选多个用户批量删除。
- 内置管理员账号不能被选择删除。建议只在初始化和紧急管理时使用，不作为日常部署账号。

人员职责变化时，建议按“调整角色或组成员 → 禁用账号 → 查看日志审计”的顺序操作。删除是不可逆的账号变更，请优先使用禁用。
