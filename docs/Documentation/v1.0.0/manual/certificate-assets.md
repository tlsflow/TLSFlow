# 证书资产

证书资产是平台保存证书版本和关联材料的地方。一个域名可以有多个版本；导入或签发新证书时，平台会新增版本并保留历史版本，便于核对、部署和回滚。

本页只负责管理证书材料。要把证书安装到服务器，请继续使用“资产中心 → 应用资产”和“证书部署”。


## 导入证书

证书导入页采用四步向导：选择来源、选择格式和输入方式、提供材料、校验并导入。系统只有在校验通过后才会保存版本。

1. 打开“证书管理 → 证书资产”，选择“导入证书”。
2. 在来源页选择“手工导入”。需要通过 ACME 申请时，选择“ACME 申请”，按向导进入 ACME 流程。
3. 选择导入格式：
   - `PEM + KEY`：提供证书内容和匹配的私钥。证书和私钥可以粘贴文本，也可以上传文件。
   - `PFX / PKCS#12`：上传 `.pfx` 或 `.p12` 文件，并填写导出密码。PFX 导入必须使用文件方式。
4. 点击“下一步”，确认材料齐全后选择“校验”。平台会检查域名、有效期、证书链和私钥是否匹配。
5. 阅读校验报告中的阻断项和警告。只有没有阻断项时，“导入”按钮才可用。
6. 导入完成后打开新版本详情，核对主域名、SAN、签发者、有效期和 SHA-256 指纹。

不要把“上传成功”当成“证书可部署”。证书链不完整、私钥不匹配或证书已过期时，校验报告会明确显示原因；先修正材料，再重新校验。

## 查看版本和使用关系

1. 在列表中选择域名，打开版本列表。
2. 使用关键词、状态和到期时间筛选版本；时间按浏览器本地时间显示。
3. 打开版本详情，查看域名集合、序列号、签发者、证书链、私钥状态和指纹。
4. 打开“使用关系”，确认该版本是否被应用资产、自动化规则或待执行计划引用。

同名证书不一定是同一份材料。准备部署或替换证书时，请同时核对域名集合、到期时间和 SHA-256 指纹。

## 删除版本

删除前先检查“使用关系”。仍被应用资产、自动化任务或待执行计划引用的版本不能直接删除。

确认没有活动引用后，在版本详情中选择“删除”，阅读风险提示并确认。删除平台记录不会清理已经写入目标服务器的文件；服务器文件需要通过相应的维护或部署流程处理。

## 部署前检查

- 版本状态为有效，且有效期覆盖计划使用时间。
- 主域名和 SAN 与实际访问地址一致。
- 私钥与叶子证书匹配，证书链状态为有效且顺序正确。
- 目标系统需要的输出格式已在证书详情的“格式配置”中准备好。
- 应用资产和部署计划选择的是本次核对过的版本。
