# 执行记录

执行记录是每次提交、部署、回滚或重试的完整结果。它用于确认任务走到了哪一步、哪个目标受影响，以及最终结果是否已经得到验证。历史记录不能编辑或删除。

## 查找和阅读记录

1. 进入“证书部署 → 执行记录”，按状态、部署计划、应用资产、运行类型或时间范围筛选。
2. 打开记录详情，先查看任务状态、运行类型、关联应用和开始时间，再查看步骤时间线。
3. 重点检查审批、执行、验证和回滚阶段的结果，以及失败步骤的错误摘要。
4. 记录中的时间按浏览器本地时间显示；密码、私钥和证书材料只显示脱敏引用。

执行记录里的密码、私钥和证书材料只显示脱敏引用。历史记录不能编辑，重试会生成一条新的记录。

记录状态应按“排队/执行中 → 成功、失败、取消或待确认”理解。待确认表示平台尚未确认目标最终状态，不等同于失败；先查看目标站点实际证书和服务状态，再决定是否恢复或重试。

## 处理失败或卡住的任务

1. 失败时从第一个失败步骤开始，检查目标、证书版本、凭据和错误代码。
2. 外部写入超时或状态待确认时，不要立即重试；先回读目标并确认是否已发生变更。
3. 目标支持恢复时，确认快照和恢复范围后发起恢复。恢复完成后再次检查目标证书和应用可访问性。
4. 仍在运行的任务可使用页面提供的“取消”或“强制结束”；不要通过重复点击或删除记录改变状态。
5. 重试会创建新的执行记录。保留原记录，便于审计和对比。
