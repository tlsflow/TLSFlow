# ACME 自动化

ACME（自动化证书管理环境）可以自动申请和续签证书，减少手工上传和到期遗漏。页面顶部会显示当前托管证书、运行中的任务和失败任务数量。

## 配置提供商

1. 进入“证书管理 → ACME 自动化”，点击“提供商设置”。
2. 点击“新增提供商”，选择内置配置或自定义 CA。
3. 填写提供商名称、目录地址、联系邮箱；页面提示需要信任链时，选择已保存的安全凭据。
4. 点击“探测目录”。如果提示需要 EAB（外部账户绑定），在账户区域选择已有 EAB 凭据，或先创建 EAB。
5. 保存后回到提供商列表，确认状态为“可用”。

## 申请和续签

1. 在 ACME 页面点击“新增申请”。
2. 填写主域名和其他域名，选择提供商、账户、密钥类型和验证方式（HTTP-01 或 DNS-01）。
3. 使用 DNS-01 时，选择对应 DNS 服务商和凭据，并填写传播等待时间。
4. 设置自动续签开关和提前续签天数，提交申请。
5. 在任务列表查看“排队中”“申请中”“签发成功”或“失败”。成功后，证书资产会新增一个版本。

> 【截图占位：新增 ACME 申请窗口，标出域名、验证方式、DNS 凭据和自动续签设置】

可以打开任务详情、编辑续签策略或手动续签。运行中的任务可以取消，但不能删除；不要通过删除证书资产来中止续签。

## 凭据和事件

DNS 服务商凭据、EAB 密钥和账户密钥都应从“系统设置 → 凭据”选择。申请成功后，自动化任务会关联新证书版本；后续部署流程会使用本次任务生成的版本。

## 失败和重试

- 目录探测失败：检查目录地址和信任链，再重新探测。
- DNS 验证失败：检查 DNS 服务商、凭据和传播等待时间。
- 任务失败：打开详情查看失败原因，修正配置后点击“重试”。
- 任务长时间运行：先查看当前阶段；确认无误后再取消，不要重复创建相同域名任务。
