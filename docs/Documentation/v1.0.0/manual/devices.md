# 设备

设备是 TLSFlow 连接和操作目标主机、网络设备或安全设备的入口。接入设备后，系统可以读取其系统信息、站点、服务和证书位置，供应用资产和部署任务选择。

设备页面位于“资产中心 → 资产”。设备与云服务资产共用一个列表；请根据“设备类别”和“管理方式”筛选，不要把在线状态直接当成“可以部署”。


## 接入前准备

请在开始前确认：

- 目标地址和管理端口可以从 TLSFlow 所在网络访问。
- 已在“系统设置 → 凭据”创建与目标匹配的凭据。密码、私钥和令牌不会在设备列表中显示。
- 你知道目标的产品类型和维护窗口。首次接入建议使用测试设备。
- 如果使用 Agent，目标主机可以访问 TLSFlow 的 Agent 接入地址，并且你有安装权限。

## 添加设备

1. 打开“资产中心 → 资产”，点击“添加资产”。
2. 在平台列表中选择目标设备或已启用的设备插件。列表会标明平台的支持状态；只有“支持”的平台可以提交。
3. 按向导填写设备名称、管理地址、端口、连接协议、TLS 校验和凭据引用。插件平台显示的字段以页面提示为准。
4. 仔细检查信息后提交。

### 使用 Agent 接入

选择 Agent 平台后，向导会生成一次性的安装命令和有效期。复制命令，在目标主机上以具有安装权限的账户执行；不要把命令或注册材料发布到工单、截图或聊天群中。执行完成后返回资产列表，等待 Agent 上线。


### 使用直接连接或插件接入

填写向导要求的连接信息后，系统会在提交时验证地址、凭据和产品身份。结果页会明确显示连接是否成功以及错误代码。连接测试是只读操作，不会修改目标设备。


## 运行发现

设备在线或连接测试成功后，打开设备的操作菜单，选择“查看详情”，再点击“重新发现”。发现会读取目标实际存在的框架、站点、服务、证书和可用能力。

发现完成后，在详情页检查：

- 设备概览：产品、系统、管理方式和最近联系时间；
- 框架和站点：站点地址、端口、协议及所属产品；
- 证书：目标上已识别的证书、有效期和指纹；
- 日志：连接、发现和其他设备操作的结果。


发现成功只说明系统读到了目标信息，不代表证书已部署。创建应用资产时，优先选择发现结果中明确可用、且与应用类型匹配的目标；部署仍需经过页面校验和执行结果验证。

## 日常维护

- 用设备类别、管理方式和健康状态筛选列表，先处理“不可达”“降级”或“未知”的设备。
- 目标地址、端口或凭据发生变化时，先编辑设备并重新运行连接测试和发现，再启动部署任务。
- 设备详情中的“重新发现”只刷新资产事实，不会自动更换证书或修改目标配置。
- 出现“可升级”操作时，核对当前版本、目标版本和维护窗口；升级完成后重新确认 Agent 在线和发现时间。
- 删除设备前，先确认没有应用资产、工作流或自动化任务引用它。删除会影响后续目标选择，无法用设备列表恢复历史配置。

## 常见问题

**连接测试失败**
检查管理地址、端口、TLS 校验设置和凭据状态。若使用内网地址，确认 TLSFlow 或 Gateway 能够访问该网络。

**Agent 已安装但列表仍未上线**
确认安装命令未过期、目标主机可以访问接入地址，并检查 Agent 服务日志。命令过期时重新生成，不要重复使用旧注册材料。

**发现结果为空或带警告**
先处理连接错误，再重新发现。只有目标插件实际能读取的资源才会出现在详情页，手工猜测路径不会补齐发现结果。

**设备显示在线但无法作为部署目标**
在线只代表最近一次通信正常。请检查目标兼容性、发现结果和所需能力，再回到应用资产向导选择目标。

**Gateway 设备如何使用**
Gateway 负责跨网络转发，不是证书部署目标。除 Gateway 外，还必须接入能够实际执行证书操作的目标设备。
