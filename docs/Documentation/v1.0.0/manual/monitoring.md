# 监控分析

监控分析用于持续观察应用资产是否可访问、当前站点实际使用的证书、访问延时、证书变化和风险事件。监控只采集并展示事实，不会自动修改证书或目标配置。

## 添加监控目标

1. 进入“监控分析”，点击“添加监控”。
2. 在应用资产下拉框中选择要观察的目标。列表会同时显示资产名称和访问地址，避免选错环境。
3. 设置“探测频率”。单位为秒，最小值为 10 秒；生产站点建议结合访问量和维护要求设置，不要为了追求实时而设置过密。
4. 阅读默认监控范围（可访问性、访问延时、证书信息和证书历史），点击“添加”。
5. 添加成功后，目标会出现在左侧“监控目标”列表中。

截图占位：添加监控窗口，展示应用资产选择、探测频率和默认监控范围说明。

## 查找和检测目标

1. 使用“应用资产”搜索框输入名称或关键字，快速缩小目标列表。
2. 使用状态下拉框按正常、警告、错误、待执行或已移除筛选；需要恢复全部目标时点击“清空筛选”。
3. 点击“检测站点”立即检测当前监控目标。检测过程中不要关闭页面或连续重复点击。
4. 点击“刷新数据”重新读取结果并更新风险信息。目标较多时可继续滚动左侧列表加载更多目标。

截图占位：监控主页面，展示左侧目标列表、搜索/状态筛选、检测站点和刷新数据按钮。

## 阅读目标详情

点击左侧目标后，右侧会显示当前目标和以下信息：

- “可访问性”和“访问延时”：判断站点当前能否访问以及响应速度。
- “当前站点实测证书”：查看指纹、主体、颁发者、序列号、有效期、链验证结果和采集时间。
- “绑定证书版本”：按实测证书变化保留历史，帮助确认站点是否已经换上目标版本。
- “风险事件”：查看证书链、域名、指纹或执行状态相关警告，以及发生和关闭时间。
- “探测历史”：查看最近 20 次探测的时间、来源、状态、延时和结果，并通过趋势图观察波动。

如果当前目标需要调整频率，可在详情顶部修改秒数；不再需要时点击“移除”。移除只停止该目标的监控，不会删除应用资产或证书。

截图占位：目标详情，展示可访问性、延时、实测证书、风险事件和探测历史区域。

## 查看 TLS 深度结果

在目标详情中点击 TLS 评分旁的“查看详情”，可打开 TLS 深度检测。根据页面标签查看：

1. 证书认证路径：确认站点证书、链证书和信任路径是否完整。
2. 协议支持：查看 TLS 版本是否符合业务客户端要求。
3. 密码套件：查看不同协议下可用的加密套件。
4. 客户端兼容性模拟：了解常见客户端画像下的握手结果。
5. 协议细节：查看检测到的握手与协议参数。
6. 点击“重新检测”获取最新结果，检测结束后再根据新的评分判断风险。

截图占位：TLS 深度详情窗口，展示评分、证书链、协议支持、密码套件和客户端兼容性标签页。

页面显示“部分结果”或“不支持”时，先查看该项的具体说明和检测快照。它可能表示当前检测范围受限、缺少相应信任根或客户端画像无法模拟，不能直接当成证书不可信。

## 处理风险与通知联动

监控发现的风险状态、通知投递和证书部署结果是三类独立信息。通知发送失败不会改变已经完成的部署，部署失败也不会自动把风险标记为已解决。处理风险时先确认站点实测证书和部署执行结果，再按组织流程关闭或继续跟踪风险；需要查看通知原因时，转到“系统设置 → 通知”的投递记录。

截图占位：风险事件列表，展示风险内容、发生时间、当前状态和关闭时间。

## 判断结果时的注意事项

- 监控结果是某一时刻的观测，出现一次超时应结合探测历史判断是否持续发生。
- “证书状态正常”只表示本次探测到的证书和链验证正常，不代表所有客户端都兼容。
- 发现站点仍使用旧证书时，先检查部署执行记录，再重新检测；不要直接在监控页面修改证书。
