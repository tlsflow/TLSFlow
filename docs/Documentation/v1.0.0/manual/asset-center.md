# 资产中心

资产中心是所有受管资源的入口。你可以在这里添加设备、查看 Agent 管理的主机、接入云服务资产，并管理 Gateway。应用资产单独位于“资产中心 → 应用”，用于把证书和具体业务入口关联起来。


## 先了解四类资源

| 资源 | 保存的内容 | 什么时候使用 |
| --- | --- | --- |
| 应用资产 | 业务名称、访问地址、证书和部署目标 | 需要为网站或应用更新证书时使用 |
| 设备 | 主机或网络设备、连接方式、健康状态和发现结果 | 提供实际执行位置和可用目标 |
| 云服务资产 | 云平台、服务范围和凭据引用 | 连接云平台并发现云资源 |
| Gateway | 网络转发节点和可用状态 | 平台无法直接访问目标时中转 |

## 推荐的准备顺序

1. 先添加设备或云服务资产，并完成连接测试。
2. 运行发现，确认平台能够读取框架、站点或云资源。
3. 需要部署证书时，再到“应用”创建应用资产并选择发现出的目标。
4. 目标位于隔离网络时，先安装并接入 Gateway，再在设备或应用连接设置中选择它。

### 添加资产

1. 进入“资产中心”，点击“添加资产”。
2. 选择资产类别和平台，填写名称、地址及页面要求的凭据引用。
3. 提交后等待连接测试完成；测试失败时先修正地址、网络或凭据。
4. 点击“发现”，检查系统、站点、云资源和可用能力。

云服务资产的添加、连接测试和发现流程与应用资产不同：它用于读取云资源，不会选择证书，也不会直接创建部署任务。阿里云 CDN 是当前正式验收的云服务类型，其他平台是否可用以页面显示和产品支持范围为准。

## 选择部署目标

| 模式 | 适用情况 |
| --- | --- |
| 无 Agent 设备 | 目标支持远程连接，但没有安装 Agent |
| 设备默认能力 | 发现结果已提供可用的系统或站点，通常优先选择 |
| 工作流覆盖 | 业务确实需要自定义步骤或特殊顺序 |
| 独立目标与工作流 | 目标不属于设备，需要单独配置工作流连接 |

优先使用发现结果中的地址、端口、服务名和证书位置；只有业务确实变化时再手工修改。发现成功只代表平台读到了目标信息，提交部署前仍需确认页面校验结果，执行后还要完成目标验证。
