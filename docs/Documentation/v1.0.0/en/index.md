# TLSFlow v1.0.0 Documentation

TLSFlow is a certificate lifecycle management platform. It centralizes certificate assets, certificate authorities, target devices, application assets, deployment execution, monitoring, and audit records.

## Start here

- Read [Installation](/v1.0.0/en/installation/) and choose [standard deployment](/v1.0.0/en/installation/standard-deployment) or [single-node deployment](/v1.0.0/en/installation/single-node-deployment).
- Read [First login](/v1.0.0/en/installation/first-login), then continue with the [user manual](/v1.0.0/en/manual/).
- Review [Developer documentation](/v1.0.0/en/developer/) for plugin and workflow extension boundaries.
