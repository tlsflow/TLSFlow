# User manual

This manual follows the current TLSFlow console menus. “Save” stores configuration; “Execute” creates a task or changes a target. Do not treat form submission as proof of deployment.

Start with the [Dashboard](/v1.0.0/en/manual/dashboard), then follow the certificate, asset, deployment, monitoring, and audit sections in the sidebar.
