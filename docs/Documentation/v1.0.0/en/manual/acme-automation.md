# ACME Automation

ACME (Automatic Certificate Management Environment) can automatically apply for and renew certificates, reducing manual uploads and expiration oversights. The page header displays the current number of managed certificates, running tasks, and failed tasks.

## Configure Provider

1. Go to "Certificate Management → ACME Automation" and click "Provider Settings".
2. Click "Add Provider" and select built-in configuration or custom CA.
3. Fill in provider name, directory URL, and contact email; when the page prompts for trust chain, select saved security credentials.
4. Click "Probe Directory". If it prompts for EAB (External Account Binding), select existing EAB credentials in the account area, or create EAB first.
5. After saving, return to the provider list and confirm the status is "Available".

## Apply and Renew

1. Click "New Application" on the ACME page.
2. Fill in main domain and other domains, select provider, account, key type, and verification method (HTTP-01 or DNS-01).
3. When using DNS-01, select corresponding DNS service provider and credentials, and fill in propagation wait time.
4. Set auto-renewal switch and days before expiration for renewal, then submit application.
5. In the task list, view "Queued", "Applying", "Issued Successfully", or "Failed". After success, the certificate asset will have a new version added.

> [Screenshot placeholder: New ACME application window highlighting domain, verification method, DNS credentials, and auto-renewal settings]

You can open task details, edit renewal strategy, or manually renew. Running tasks can be canceled but not deleted; do not stop renewal by deleting certificate assets.

## Credentials and Events

DNS service provider credentials, EAB keys, and account keys should all be selected from "System Settings → Credentials". After successful application, the automation task will associate with the new certificate version; subsequent deployment processes will use the version generated by this task.

## Failure and Retry

- Directory probe failure: Check directory URL and trust chain, then probe again.
- DNS verification failure: Check DNS service provider, credentials, and propagation wait time.
- Task failure: Open details to view failure reason, correct configuration, then click "Retry".
- Task running for long time: First check current stage; after confirming no issues, cancel; do not repeatedly create tasks for the same domain.
