# Licenses

Navigate to "System Settings → Licenses" to view current authorization version, authorization status, validity period, version compatibility, application asset quota, concurrent execution quota, plugin count, and enabled features. Status may display as unlicensed, valid, grace period, expired, revoked, or time anomaly detected.

After opening the page, first click "Refresh" to confirm the status matches current purchase records; "View Versions" on the page allows comparison of Community, Business, and Enterprise edition feature boundaries without directly changing current authorization.

## Offline Activation

1. Click "Export Offline Request" and save the generated JSON file to a controlled location.
2. Submit the file to the licensing authority for processing. Do not modify file contents or copy to public locations.
3. After receiving the authorization file, click "Import License File" to select the JSON file; alternatively, paste the complete content into the "Import License JSON" text box and submit.
4. After the page prompts successful import, click "Refresh" to confirm status is "Valid" and "Version Compatibility" shows compatible.

> [Screenshot placeholder: License page highlighting authorization status, quotas, authorized features, and "Export Offline Request/Import License File" actions]

License files can only be generated by the licensing authority. When "Signature verification failed" appears or status changes to revoked, do not manually modify the JSON; obtain a new file from the licensing authority. Importing a license does not change users or historical execution records; when quotas are exhausted, licenses expire, or versions are incompatible, refer to actual page status and restrictions.
