# Licenses

Open “System Settings → Licenses” to review the current plan, authorization state, validity, version compatibility, application-asset quota, concurrent-execution quota, plugin quota, and enabled features. The state can be unconfigured, valid, in grace period, expired, revoked, or affected by a detected time anomaly.


## Review License Status

Select “Refresh” after opening the page and confirm that the plan and validity match your purchase record. “Upgrade” opens a plan and feature comparison; it does not change the current license.

Pay attention to:

- **Version compatibility**: whether the license applies to the running product version.
- **Application-asset quota**: used and available capacity; reaching the limit prevents additional restricted assets.
- **Concurrent execution and plugin quotas**: limits simultaneous tasks and enabled plugins.
- **Integrity warnings**: stop importing and contact the licensing authority when signature verification or tamper warnings appear.

## Offline Activation

1. Select “Export Offline Request” and save the downloaded JSON file in a controlled location.
2. Send it to the licensing authority. Do not edit the content or upload it to public storage or chat tools.
3. When the authority returns a license or activation response, select “Import License” and choose the JSON file. You can also paste the complete JSON into the text area and import it.
4. After a successful import, select “Refresh” and confirm that the state, validity, and version compatibility are correct.


Licenses and activation responses must be generated by the licensing authority. If signature verification fails, the installation identifier does not match, or the license is revoked, do not edit the JSON manually; request a new file. Importing a license does not change users, application assets, or historical execution records.
