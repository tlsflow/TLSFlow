# Developer documentation

This section describes the current TLSFlow plugin and workflow boundaries. Start with [Host plugin capabilities](/v1.0.0/en/developer/host-plugin-capabilities), then use [Plugin development](/v1.0.0/en/developer/plugin-development) and [Workflow development](/v1.0.0/en/developer/workflow-development) for implementation details.

Only documented host capabilities may be used as a plugin contract. Undocumented interfaces, permissions, and execution steps are not stable extension points.
