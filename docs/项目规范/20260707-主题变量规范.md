# GCAC 前端主题变量规范

> 版本：1.0 | 更新日期：2026-07-07 | 适用范围：`web/src/` 所有前端代码

---

## 一、概述

GCAC 前端采用**语义化 CSS 自定义属性（CSS Custom Properties）**作为唯一的设计令牌系统，实现亮色/暗色双主题无缝切换。

- **不使用** Tailwind CSS、UnoCSS 或任何原子化 CSS 框架。
- **不使用** CSS-in-JS 方案。
- **所有设计令牌**统一定义在 `web/src/design-system/tokens/index.css`，全项目仅此一处来源。

主题切换通过 `<html>` 元素的 `data-theme` 属性驱动：移除或设置 `data-theme="light"` 为亮色、`data-theme="dark"` 为暗色。

---

## 二、CSS 变量命名规范

### 2.1 命名格式

```
--gc-{类别}-{属性}[-{修饰符}]
```

| 部分 | 说明 |
|---|---|
| `gc` | 项目固定前缀 |
| `{类别}` | 取值：`color`、`space`、`font`、`radius`、`shadow`、`gradient` |
| `{属性}` | 语义化属性名，如 `bg`、`text`、`border`、`primary`、`surface` |
| `{修饰符}` | 可选，进一步细分，如 `strong`、`muted`、`soft`、`hover`、`sm` |

### 2.2 已定义令牌类别

#### 颜色 (`--gc-color-*`)

按**语义角色**命名，而非按色值命名：

| 语义组 | 变量示例 | 说明 |
|---|---|---|
| 背景 | `--gc-color-bg`、`--gc-color-bg-strong` | 页面底色 |
| 表面 | `--gc-color-surface`、`--gc-color-surface-*` | 卡片、面板、弹窗、表单控件等容器背景 |
| 文字 | `--gc-color-text`、`--gc-color-text-muted`、`--gc-color-text-strong`、`--gc-color-text-soft`、`--gc-color-text-inverse`、`--gc-color-text-inverse-muted` | 各级文字颜色 |
| 边框 | `--gc-color-border`、`--gc-color-border-subtle`、`--gc-color-border-soft`、`--gc-color-border-strong`、`--gc-color-border-muted` | 分隔线、输入框边框 |
| 主色 | `--gc-color-primary`、`--gc-color-primary-hover`、`--gc-color-primary-strong`、`--gc-color-primary-border`、`--gc-color-primary-border-strong`、`--gc-color-primary-weak`、`--gc-color-primary-soft` | 品牌主色调及变体 |
| 语义色 | `--gc-color-success`、`--gc-color-warning`、`--gc-color-danger`、`--gc-color-info` | 成功/警告/危险/信息 |
| 语义色配套 | `--gc-color-{semantic}-bg`、`--gc-color-{semantic}-soft`、`--gc-color-{semantic}-border` | 对应的背景、软背景、边框 |
| 辅助 | `--gc-color-accent-purple`、`--gc-color-code-bg`、`--gc-color-muted`、`--gc-color-muted-bg`、`--gc-color-focus`、`--gc-color-focus-ring`、`--gc-color-backdrop` | 代码块底色、禁用态、聚焦环、遮罩等 |

**语义色四件套模式：** 每个语义色（success / warning / danger / info）必须有 4 个配套变量：

```
--gc-color-{semantic}          → 前景色（文字/图标）
--gc-color-{semantic}-bg       → 背景色
--gc-color-{semantic}-soft     → 更柔和的背景色
--gc-color-{semantic}-border   → 边框色
```

#### 阴影 (`--gc-shadow-*`)

| 变量 | 用途 |
|---|---|
| `--gc-shadow-sm` | 小元素（标签、徽章） |
| `--gc-shadow-md` | 卡片默认悬浮 |
| `--gc-shadow-lg` | 弹窗、下拉菜单 |
| `--gc-shadow-hover` | 鼠标悬浮反馈 |
| `--gc-shadow-overlay` | 模态框遮罩 |
| `--gc-shadow-primary` | 主色按钮聚焦/悬浮 |
| `--gc-shadow-focus` | 通用聚焦环 |

#### 间距 (`--gc-space-*`)

`--gc-space-hairline` 用于 `1px` 发丝线边框；`--gc-space-1` ~ `--gc-space-10` 对应 `4px` ~ `40px`。不允许在组件中硬编码 `px` 间距值。

#### 边框 (`--gc-border-*`)

`--gc-border-width-default` 表示默认边框宽度。组件必须通过该语义变量设置边框宽度，不得使用裸 `px` 或 `thin`、`medium`、`thick` 等关键字。

#### 排版 (`--gc-font-*`)

| 类别 | 变量 |
|---|---|
| 字体族 | `--gc-font-family`（SF Pro → PingFang SC → Microsoft YaHei 降级链） |
| 字号 | `--gc-font-size-xs`(12px) / `sm`(14px) / `md`(16px) / `lg`(20px) / `xl`(28px) / `2xl`(40px) |

#### 圆角 (`--gc-radius-*`)

| 变量 | 值 | 典型用途 |
|---|---|---|
| `--gc-radius-sm` | 10px | 小按钮、标签、输入框 |
| `--gc-radius-md` | 14px | 卡片、面板 |
| `--gc-radius-lg` | 18px | 大卡片、弹窗 |
| `--gc-radius-xl` | 24px | 最大圆角（模态框等） |

#### 通用尺寸与状态 (`--gc-*`)

| 变量 | 典型用途 |
|---|---|
| `--gc-border-width` | 标准边框宽度 |
| `--gc-control-height-md` | 标准中等控件高度 |
| `--gc-size-card-min` | 响应式指标卡的最小尺寸基准 |
| `--gc-size-modal-wide` | 新建、编辑向导类宽模态框的最大宽度 |
| `--gc-opacity-disabled` | 禁用态透明度 |

#### 渐变 (`--gc-gradient-*`)

`--gc-gradient-surface`、`--gc-gradient-surface-soft`、`--gc-gradient-primary`、`--gc-gradient-brand`、`--gc-gradient-hero`、`--gc-gradient-progress`。渐变内部引用其他 `--gc-color-*` 变量，随主题自动切换。

## 三、旧样式桥接变量

`index.css` 中存在一批 `--gc-color-legacy-*` 变量（位于 `/ * 旧样式裸色桥接变量 */` 注释块内），用于渐进迁移旧组件中直接使用的裸色值：

- 格式：`--gc-color-legacy-{hex}`（如 `--gc-color-legacy-071427`）或 `--gc-color-legacy-rgb-{r}-{g}-{b}-a{alpha}p`（如 `--gc-color-legacy-rgb-125-211-252-a10p`）
- **新增代码不得使用** `--gc-color-legacy-*` 变量，必须使用上方语义化变量。
- 旧代码在迁移完成后应逐步清除 `legacy-*` 引用。

## 四、主题切换机制

### 4.1 驱动方式

```css
/* 亮色（默认） */
:root,
:root[data-theme="light"] { ... }

/* 暗色 */
:root[data-theme="dark"] { ... }
```

切换主题的本质是修改 `<html data-theme="...">` 属性，CSS 层叠自动替换所有 `var(--gc-*)` 的实际值。

### 4.2 代码调用链

```
GcThemeToggle.vue（用户点击）
  → appStore.setTheme('light'|'dark')
    → applyThemeToDocument(theme)   // 设置 document.documentElement.dataset.theme
    → updatePreferences()            // 同步偏好到后端
    → writeCachedPreferences()       // 写入 localStorage
```

TypeScript 入口：`web/src/preferences/app-preferences.ts` → `applyThemeToDocument()`

### 4.3 组件开发中的主题适配规则

**强制要求：**

- 组件 `<style scoped>` 中**禁止**出现硬编码的颜色值（如 `#ffffff`、`rgb(0,0,0)`、`#333` 等）。
- **必须**使用 `var(--gc-color-*)` 引用语义化变量。
- 如需新增颜色变量，**必须**在 `tokens/index.css` 中同步定义亮色和暗色两套值。
- 不允许在组件内通过 `@media (prefers-color-scheme: dark)` 覆盖颜色——暗色切换完全由 `data-theme` 属性驱动。

**正确示例：**

```css
/* ✅ 正确 */
.my-card {
  background: var(--gc-color-surface);
  border: 1px solid var(--gc-color-border);
  color: var(--gc-color-text);
  border-radius: var(--gc-radius-md);
  box-shadow: var(--gc-shadow-md);
}

.my-card__title {
  color: var(--gc-color-text-strong);
  font-size: var(--gc-font-size-lg);
}

.my-card__muted {
  color: var(--gc-color-text-muted);
  font-size: var(--gc-font-size-sm);
}
```

**错误示例：**

```css
/* ❌ 错误——硬编码颜色 */
.my-card {
  background: #ffffff;
  border: 1px solid #e5e7eb;
  color: #111827;
}

/* ❌ 错误——硬编码间距 */
.my-card {
  padding: 16px;        /* 应使用 var(--gc-space-4) */
  margin-bottom: 8px;    /* 应使用 var(--gc-space-2) */
}

/* ❌ 错误——通过媒体查询覆盖暗色 */
@media (prefers-color-scheme: dark) {
  .my-card { background: #1f2937; }
}
```

### 4.4 如果确实需要新颜色

按以下步骤操作：

1. 在 `tokens/index.css` 的亮色块 (`:root[data-theme="light"]`) 中新增变量
2. 在暗色块 (`:root[data-theme="dark"]`) 中定义对应的暗色值
3. 命名遵循 `--gc-color-{语义角色}` 规范
4. 在组件中使用 `var(--gc-color-xxx)` 引用

## 五、Status/Risk 色调系统

`web/src/design-system/status/status-map.ts` 和 `risk-map.ts` 定义了统一的色调类型：

```typescript
type StatusTone = 'success' | 'warning' | 'danger' | 'info' | 'muted'
```

设计系统组件（`GcStatusTag`、`GcRiskBadge`、`GcCapabilityBadge`）通过 CSS class 修饰符映射到语义色变量：

```css
.gc-tag--success { color: var(--gc-color-success); background: var(--gc-color-success-bg); }
.gc-tag--warning { color: var(--gc-color-warning); background: var(--gc-color-warning-bg); }
.gc-tag--danger  { color: var(--gc-color-danger);  background: var(--gc-color-danger-bg); }
.gc-tag--info    { color: var(--gc-color-info);    background: var(--gc-color-info-bg); }
.gc-tag--muted   { color: var(--gc-color-muted);   background: var(--gc-color-muted-bg); }
```

**新增组件如果需要状态色调**，必须复用 `StatusTone` 类型和相同的 CSS class → 语义色变量映射模式，不得自行定义新的颜色映射。

## 七、全局布局 CSS

`web/src/design-system/patterns/layout.css` 提供全局共享的 BEM 布局类（`.gc-shell`、`.gc-card`、`.gc-button`、`.gc-page`、`.gc-form-panel` 等）。

- 这些类中的颜色、间距、阴影、圆角也同样通过 `var(--gc-*)` 引用。
- 新增全局布局类时，必须在 `layout.css` 中定义，不得在各页面重复手写相同样式。

## 八、检查清单

新建或修改前端组件时，确认以下事项：

- [ ] 无硬编码颜色值（`#xxx`、`rgb()`、`hsl()` 等）
- [ ] 颜色引用全部使用 `var(--gc-color-*)` 格式
- [ ] 间距使用 `var(--gc-space-*)`，不写裸 `px`
- [ ] 边框宽度使用 `var(--gc-border-width-default)`
- [ ] 圆角使用 `var(--gc-radius-*)`
- [ ] 阴影使用 `var(--gc-shadow-*)`
- [ ] 字号使用 `var(--gc-font-size-*)`
- [ ] 字体族使用 `var(--gc-font-family)`
- [ ] 不通过 `@media (prefers-color-scheme: dark)` 覆盖颜色
- [ ] 不新增 `--gc-color-legacy-*` 变量
- [ ] 可复用 UI 组件放入 `design-system/components/`
- [ ] 全局布局样式放入 `design-system/patterns/layout.css`
