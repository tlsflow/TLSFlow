# 应用资产当前版本迁移基线

## 目的

应用资产的配置表达“要执行的能力和工作流”，不能表达“某个历史插件包”。插件或工作流发布后，下一份计划必须解析当前生效版本；已经创建的计划、运行、审批、Agent Plan 和恢复账本仍保留原始版本与摘要。

## 数据迁移矩阵

| 数据位置 | 历史版本字段 | 新用途 | 迁移规则 |
| --- | --- | --- | --- |
| `unified_plugin_bindings` | `plugin_version_id` | `plugin_id` 是配置身份，版本字段仅供旧读取兼容 | 从插件版本回填 `plugin_id`；运行期按 `plugin_id` 找当前 `ENABLED` 版本 |
| `plugin_capability_assignments` | `plugin_version_id` | `plugin_id + capability_key` 是配置身份 | 从插件版本回填 `plugin_id`；能力解析不再比较旧版本 ID |
| `workflow_execution_bindings` | `plugin_version_id`、`workflow_version_id`、`FIXED` | `plugin_id + capability_key + workflow_key + workflow_template_id` 是配置身份 | 可解析记录清空旧版本 ID 并改为 `CURRENT`；无法回填 `plugin_id` 的记录保留旧字段并在读取时标记不支持 |
| 部署计划、运行、审批、Agent Plan、恢复账本 | 插件/工作流版本与 Hash | 不可变执行快照 | 不迁移、不动态重解析 |

## 不支持处理

无法从历史 `plugin_version_id` 找到插件身份的工作流绑定，不自动猜测替代插件。运行期返回稳定的 `WORKFLOW_EXECUTION_BINDING_CURRENT_CHAIN_MISSING` 诊断，并在兼容性记录中标为 `UNSUPPORTED`；管理员需要重新保存该资产配置。

迁移脚本只做确定性的字段回填和状态初始化，可重复执行，不会修改历史计划或运行记录。
