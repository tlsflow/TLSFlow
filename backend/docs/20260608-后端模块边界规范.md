# 20260608-后端模块边界规范

## 核心判断

Controller 只负责 HTTP 入参和出参，Application Service 负责编排，Domain Service 负责纯规则，Repository 负责数据访问。谁越界，谁就是在制造屎山。

## 允许依赖

```text
Controller -> Application Service
Application Service -> Domain Service
Application Service -> Repository 接口
Application Service -> Queue Port
Application Service -> Audit Port
业务模块 -> common
业务模块 -> shared/contracts
```

## 禁止依赖

```text
Controller -> Repository
Domain Service -> HTTP Response
Module A -> Module B 私有 Repository
Repository -> Controller DTO
```
